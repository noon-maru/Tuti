# Tuti bundled fonts

- LINE Seed KR: https://seed.line.me/src/images/fonts/LINE_Seed_Sans_KR.zip
  (2023.09.06 배포본), Regular/Bold WOFF2(web), WOFF(PDF).
- NanumSquareRound: https://hangeul.naver.com/hangeul_static/webfont/zips/nanum-square-round.zip
  (2017 배포본), Regular/Bold TTF(web/PDF).
- Pretendard: 기존 v1.3.9 정적 배포본, 운영 센터용.

폰트 바이너리는 수정하지 않았다. 각 디렉터리의 LICENSE에 저작권·OFL 1.1 전문을
포함한다. 사용자 화면의 역할 및 PDF 등록 기준은 docs/pdf-fonts.md를 참고한다.
