# 관리자 콘솔

관리자 콘솔은 `/admin`에서 접근한다. 화면 표시 여부와 관계없이 모든
`/api/admin/*` 요청은 서버에서 현재 사용자의 DB 권한을 다시 확인한다.

## 최초 관리자 지정

먼저 관리자 마이그레이션을 적용한다.

```bash
pnpm db:deploy
```

인증 공급자와 연결된 이메일 계정을 관리자로 승격한다.

```bash
pnpm admin:promote admin@tuti.today
```

일반 사용자로 되돌리거나 다른 역할을 명시하려면 다음 명령을 사용한다.

```bash
pnpm admin:role -- --email admin@tuti.today --role user
```

마지막 관리자는 관리자 화면에서 강등할 수 없다. CLI 변경은 비상 복구에도
사용할 수 있으며 모든 변경은 시스템 로그에 남는다.

## 관리 범위

- 대시보드: 사용자, 관리자, 노출 장소, 검토 대기 장소, 신고, 당일 로그 수
- 로그: 계정 로그인, 기록 생성·수정·삭제·공개, 신고와 관리자 작업 검색
- 장소: 출처와 공공데이터 ID 확인, 검토 상태와 추천 노출 여부 변경
- 신고: 상태 변경, 신고 대상 기록 강제 삭제
- 1:1 문의: 문의 검색, 상태 변경, 사용자에게 노출할 답변 등록
- 권한: 이메일 또는 사용자 ID 검색, 역할 변경과 계정 강제 삭제
- 설정: 공공데이터 자동 승인, 신고 접수, 서비스 운영 안내 문구
- 추천 시뮬레이터: 위치·지역·질문 응답별 실제 추천 실행과 후보 점수 진단

## 추천 시뮬레이터

`/admin/recommendation-simulator`에서 현재 위치, 위치 없이 선택한 지역 또는
전국 조건을 재현한다. 일반 추천 API와 같은 후보 조회, 대중교통 경로 계산,
혼잡도 보강 및 피로도 정렬 파이프라인을 사용한다.

결과에는 원천 후보 수, 정밀 비교 후보 수, 최종 추천 6곳과 다음 진단값을
표시한다.

- 초기·최종 순위와 선정 여부
- 직선거리와 실제 대중교통 예상시간
- 기본 피로도, 거리, 이동시간, 이동 범위, 분위기, 혼잡도, 에너지 점수
- 사용자에게 표시되는 추천 문구와 세부 근거
- 장소 유형 다양성 또는 최종 순위에 따른 제외 사유
- 추천 알고리즘 버전과 전체 JSON 응답

총점이 낮을수록 현재 사용자 상태에서 부담이 낮은 장소다. 음수 항목은 추천
보너스이고 양수 항목은 부담 가산점이다. 시뮬레이션은 실제 추천 실행이나 행동
퍼널에 저장하지 않는다.

## 공공데이터 장소 입력 규칙

공공데이터 동기화 모듈은 `source`에 공급자 식별자, `sourceId`에 공급자의
원본 장소 ID를 저장한다. 자동 승인이 꺼져 있으면 `reviewStatus`를
`pending`으로 저장해야 한다. 추천 API에는 `approved`이면서 `isActive`인
장소만 포함된다.

관광 데이터의 `장소 원본` 탭에서는 추천 후보로 연결된 TourAPI 장소를 여러 개
선택해 승인·노출 또는 거절할 수 있다. 개별 원본을 열면 추천용 제목, 설명,
대표 이미지, 이동 난이도와 분위기 태그를 보정할 수 있다. 원본에 좌표나 대표
이미지가 없어 후보를 만들 수 없는 항목은 승인 대상에서 제외된다. 승인된 장소의
편집 필드는 이후 원본 동기화에서 덮어쓰지 않는다.

## 로그 범위

관리자 콘솔의 로그는 검색 가능한 애플리케이션 감사 로그다. Docker 표준
출력이나 인프라 로그 전체를 복제하지 않는다. 컨테이너 장애와 런타임 원문
로그는 기존 운영 로그 수집 경로에서 확인한다.

## 계정 강제 삭제

계정 강제 삭제는 현재 로그인한 관리자 본인과 마지막 관리자에게 사용할 수
없다. 사용자 세션, 인증 공급자 연결, 기록은 DB에서 제거되며 기록 이미지도
오브젝트 스토리지에서 함께 삭제한다. 감사 로그와 신고 추적 정보는 보존한다.
기존 1:1 문의는 운영 이력을 위해 본문을 유지하되 요청자 ID와 이메일을
익명화한다.

## 1:1 문의

사용자는 메인 메뉴의 `1:1 문의`에서 문의를 작성하고 `내 문의`에서 처리
상태와 관리자 답변을 확인한다. 웹과 Capacitor 앱 모두 동일한 세션 API를
사용한다. 관리자 답변은 이메일 발송과 별개이며 앱 내 문의 내역에 표시된다.
