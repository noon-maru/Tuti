# 관리자 콘솔

관리자 콘솔은 `/admin`에서 접근한다. 화면 표시 여부와 관계없이 모든
`/api/admin/*` 요청은 서버에서 현재 사용자의 DB 권한을 다시 확인한다.

## 최초 관리자 지정

먼저 관리자 마이그레이션을 적용한다.

```bash
pnpm db:deploy
```

인증 공급자와 연결된 이메일 계정을 관리자로 승격한다.

```bash
pnpm admin:promote admin@tuti.today
```

일반 사용자로 되돌리거나 다른 역할을 명시하려면 다음 명령을 사용한다.

```bash
pnpm admin:role -- --email admin@tuti.today --role user
```

마지막 관리자는 관리자 화면에서 강등할 수 없다. CLI 변경은 비상 복구에도
사용할 수 있으며 모든 변경은 시스템 로그에 남는다.

## 관리 범위

- 대시보드: 사용자, 관리자, 노출 장소, 검토 대기 장소, 신고, 당일 로그 수
- 로그: 계정 로그인, 기록 생성·수정·삭제·공개, 신고와 관리자 작업 검색
- 장소: 출처와 공공데이터 ID 확인, 검토 상태와 추천 노출 여부 변경
- 신고: 상태 변경, 신고 대상 기록 강제 삭제
- 권한: 이메일 또는 사용자 ID 검색, 사용자·관리자 역할 변경
- 설정: 공공데이터 자동 승인, 신고 접수, 서비스 운영 안내 문구

## 공공데이터 장소 입력 규칙

공공데이터 동기화 모듈은 `source`에 공급자 식별자, `sourceId`에 공급자의
원본 장소 ID를 저장한다. 자동 승인이 꺼져 있으면 `reviewStatus`를
`pending`으로 저장해야 한다. 추천 API에는 `approved`이면서 `isActive`인
장소만 포함된다.

## 로그 범위

관리자 콘솔의 로그는 검색 가능한 애플리케이션 감사 로그다. Docker 표준
출력이나 인프라 로그 전체를 복제하지 않는다. 컨테이너 장애와 런타임 원문
로그는 기존 운영 로그 수집 경로에서 확인한다.
