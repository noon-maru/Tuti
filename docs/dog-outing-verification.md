# 반려견 외출 추천·작성 연결 검증

기준: 2026-11-17, `feat/dog-outing-engine-v2`. 개발 DB·공개 좌표·합성 계정 시험 결과다.
운영 배포, 스토어 업로드, 실제 시설 정책 확인 완료나 iOS/Android 실기기 검증을 뜻하지 않는다.

## 1. 실제 추천 품질

공식 동반 목록의 9천여 곳을 모두 외출 목적지로 해석하면 안 된다. 개발 자료에서 8,639곳은 쇼핑 유형이었다.
첫 점검에서는 호수약국이 수변, 스파오가 스파, 민예품 상점이 사찰로 분류돼 산책 결과에 포함됐다.
공통 구 분류기의 상호 부분 문자열 추정과 공식 동반 등록을 그대로 목적지로 사용한 결과였다.

다음 규칙으로 수정했다.

- 개별 쇼핑 매장은 외출 추천에서 구분한다. 원문·장소 자체를 삭제하거나 기록 자동완성에서 지우지 않는다.
- 시장·상점가·쇼핑몰 자체와 그 안의 개별 지점을 구분한다.
- 음식점·숙박·쇼핑 상호의 ‘섬·호수·스파·사’만으로 자연·회복·유산을 추정하지 않는다.
- 카페는 공식 분류를 우선한다. 쇼핑 유형의 상호에 카페·티하우스가 있어도 카페 분류 근거 없이 승격하지 않는다.
- 선택한 목적에 맞는 후보를 우선 채운다. 다양성 때문에 카페 2곳만 남기고 다른 유형을 먼저 넣지 않는다.
- 목적 후보가 부족하면 다른 동반 장소를 보충하되 그 사실을 추천 설명에 표시한다. 거리·동반 제한은 풀지 않는다.

서울 중심·경주 불국동 인근·제주시 중심의 공개 좌표, 직선 반경 20km, 차 없이,
8kg·목줄 착용·이동장 미사용 조건으로 확인했다.

| 지역 | 산책 목적 일치 / 표시 | 카페 목적 일치 / 표시 | 나들이 목적 일치 / 표시 |
| --- | ---: | ---: | ---: |
| 서울 | 6 / 6 | 6 / 6 | 6 / 6 |
| 경주 불국동 인근 | 5 / 6 | 0 / 6 | 6 / 6 |
| 제주 | 3 / 6 | 1 / 6 | 6 / 6 |

서울 산책 상위는 인사동·익선동 한옥거리·서울로 7017·남산순환나들길·이촌한강공원·노들섬이다.
카페 상위는 스태픽스·카페우리·새들러하우스·카페 아래로·그란스 다산·비비하우스다.
경주 카페 0건은 ‘카페가 실제로 없다’가 아니라 현재 확보한 공식 동반 자료·반경·조건에서 확인된 후보가 없다는 뜻이다.

목적별 9회 외에 3지역×10개 조건 조합을 추가 검사했다. 조건 미입력, 자동차의 2km 하한,
5/20/60/200km 반경, 익일 당일치기·1박·시점 미지정, 30kg, 다견, 목줄 미준비, 이동장 사용을 포함한다.
알려진 제한과 공식 미확인 표시, 숙박시설의 일상 외출 혼입 방지, 최초 추천 외부 API 요청 0회를 확인했다.

최종 전국 공개 카탈로그 집계(거리 중심점 없는 관리자용 조회, short·차 없이·8kg·목줄·이동장 미사용):

| 단계 | 건수 |
| --- | ---: |
| 기본 정보·공식 동반 근거 준비 | 9,237 |
| 숙박·폐쇄 등 외출 정책 통과 | 9,174 |
| 개별 생활 구매점을 구분한 외출 목적지 | 557 |
| 알려진 동반 제한 통과 | 495 |

이는 전국을 한 번에 사용자에게 추천한다는 뜻이 아니다. 실제 요청은 위치·선택 지역으로 좁힌다.
감사 결과는 `distanceEligible`, `destinationEligible`, `companionEligible`을 분리한다.
숫자를 늘리기 위해 개별 매장을 다시 넣거나 자료가 없는 장소를 동반 가능으로 만들지 않는다.

## 2. 신규·누락 정보 보완

상위 노출 29곳을 조사하고 누락·좌표 문제를 함께 확인했다. 국문 공식 API 36회로 16곳의 상세 자료를
수집했으며 외부 LLM·지도 검색·새 제공자는 사용하지 않았다. 환경변수 원문과 인증정보는 출력하지 않았다.

- 단우물카페·스테이 앤드 스튜디오 여여재 2곳을 국문 기본 정보로 신규 등록했다.
- 기흥레스피아호수공원은 비정상 기존 좌표를 국문 상세의 정상 좌표로 복원했다. 명시적 옵션에서만 허용하며 정상 좌표·수동 편집은 덮어쓰지 않는다.
- 오산반려동물테마파크는 국문 상세와 전용 목록의 좌표 모두 국내 범위 밖이었다. 주소만으로 임의 추정하지 않고 등록을 보류했다.
- 공식 동반 불가 2곳·안내견 전용 1곳은 제외 사유를 명확히 했다. 공식 구역이 없는 3곳은 여전히 검토 대기다.
- 기존 운영 제외 390곳은 유지했다. 최종 카탈로그 9,633행의 PostGIS 좌표가 유효함을 확인했다.
- 13곳의 빈 소개·전화·운영시간 등 60개 필드와 공식 사진 URL 1개를 보완했다. 기존 편집·사진·출처/저작권 표기는 유지한다.
- 최종 상위 표본 29곳은 소개가 모두 있다. 사진 미제공 3곳과 익선동 한옥거리의 운영시간 미제공은 그대로 표시한다. 사진이나 24시간 운영을 만들어 넣지 않는다.

수집 사본은 Git에서 제외된 0600 파일이다.

| `.tourism-data/dog-details/` 파일 | SHA-256 |
| --- | --- |
| `2026-11-17T02-08-59-151Z.json` | `8c1d5204313fcd8e9bf64ca23ccf54b5d72ee93a8b8fa31015afdfcbd7394311` |
| `2026-11-17T02-14-14-250Z.json` | `3d274de8ceea5cc5b606f512fbfe1ba0569ea754c6bd0ef250c1c0f6203d8044` |

`scripts/supplement-dog-place-details.ts --collect ID1,ID2`는 최대 20곳의 공개 자료만 수집한다.
파일 경로만 주면 DB 반영 계획을 조회한다. 적용에는 `--apply --expected-sha256 HASH`가 필요하다.
신규 기본 정보 등록·비정상 좌표 복원은 별도 `--register-basics` 옵션을 요구한다.
기존 원문·편집값을 보존하며 장소별 트랜잭션·동시 수정 검사를 적용한다. 파일 전체가 한 트랜잭션은 아니다.
운영에 같은 자료를 넣을 때는 해당 DB의 기존 편집·제외 상태로 다시 dry-run해야 한다.

## 3. 외출 → 마디 → 다시 읽기

| 확인된 끊김 | 수정 |
| --- | --- |
| 약관 화면으로 보내면서 작성·선택 책 URL 소실 | 허용된 내부 작업을 `returnTo`로 보존하고 동의 후 직접 복귀 |
| 약관에서 로그인으로 이동하면 원래 작업 소실 | 로그인 복귀 검증에서도 한 단계의 안전한 작업 경로 보존 |
| 익명 계정 병합 후 선택 책의 owner 힌트가 구 계정 ID로 남음 | 인증 성공 뒤 새 세션 ID로 탐색 맥락을 연결하고 서버에서 책 권한 재확인 |
| 다음에 갈 공간 저장·나중에 남기기에서 책 소실 | 현재 계정에 묶인 책 ID 보존, 다른 계정·소유자 미상 맥락은 전달하지 않음 |
| 다른 장소의 이전 초안이 새 장소에 적용 | 계정·책·공유 범위에 더해 장소별 초안 구분, 기존 초안은 임의 삭제하지 않음 |
| 저장 후 책 연결을 다시 요청하는 경로 | 원자 저장 결과를 사용하고 `focusEntryId`로 방금 쓴 쪽만 표시 |
| 작성 취소 시 history.back으로 중간 로그인 화면에 복귀 | 작은 여행 시작은 작은 여행으로, 지정 책 시작은 해당 책으로 복귀 |
| 책장과 작은 여행의 이어 남기기 유효성 차이 | 동일한 소유자·시각·7일 만료 검사 사용 |

복귀 URL은 권한이 아니다. 임의 외부 주소·토큰·중첩 entry 복귀는 전달하지 않는다.
일반 첫 진입(`/`)은 작업 복귀로 취급하지 않아 기존 소개 흐름을 유지한다.
작성 전 책의 최신 권한과 공유 범위를 다시 읽고 저장 API에서 소유권·참여 권한·공유 상태·revision을 검사한다.
장소는 편집 가능한 제안이며 URL을 열거나 출발했다고 방문·마디를 자동 생성하지 않는다.
작은 여행에서 선택 책으로 작성해도 시작 계측은 explore로 남기고 기존 추천 행동과 연결한다.

## 검증 경계

- 공개 개발 DB의 자료·좌표·추천 결과를 검사했다. 실제 사용자 기록의 조회·변경은 수행하지 않았다.
- 실제 React 흐름의 핸들러를 합성 서비스/브라우저 경계로 구동해 로그인·동의 복귀, 단일 저장·연결, 방금 쓴 쪽 복귀를 검사했다.
- 격리 PostgreSQL에서 좌표 복원·수동 제외 보존·멱등 등록·충돌 롤백을 검사했다.
- 전체 회귀는 1,210개 중 1,208개 통과·2개 건너뜀·실패 0개다. 마지막 인증·등록 보완 관련 15개도 별도로 통과했다.
- TypeScript·변경 파일 ESLint·문서 링크·승인 약관 묶음 무결성 검사를 통과했다. 약관 원문은 바꾸지 않았다.
- Impeccable의 예외 상황 점검 기준으로 흐름과 복귀 문구를 정리했다. 이번 작업은 화면 재디자인이 아니다.
- 실기기 터치·소셜 로그인 제공자 UI·운영 적용·Actions 릴리스 빌드는 별도 검증 대상이다.

초기 알고리즘과 운영 전환 순서는 [동반 추천 문서](./pets-and-dog-outings.md)를 따른다.
