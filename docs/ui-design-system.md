# Tuti 사용자 화면의 공통 디자인 규칙

작은 여행에서 사용하던 Pretendard, 흰 바탕, 파랑·연두, 둥근 조작부를 책장에도 적용한다.
정체성을 교체하는 리디자인이 아니라 같은 앱의 조작 UI를 맞추는 기준이다.

## 기준 코드

- 색상·기본 수치: [tokens.ts](../src/styles/tokens.ts)
- 역할별 CSS 변수: [GlobalStyles.tsx](../src/app/GlobalStyles.tsx)
- 제목·본문·필드 조합: [typography.ts](../src/shared/ui/typography.ts)
- 공용 버튼: [buttons.tsx](../src/shared/ui/buttons.tsx)
- 화면 여백·safe area: [ScreenFrame.tsx](../src/features/tuti/components/ScreenFrame.tsx)

## 글자와 공간

| 역할 | 규칙 |
| --- | --- |
| 하위 화면 제목 | `screenTitleStyles`, 20–22px, 600, 행간 1.4 |
| 단계별 질문 | `sectionHeadingStyles`, 24–26px, 600 |
| 책장 홈 헤더 | 제목·권수를 반복하지 않고 현재 보기·새 하루마디·더보기를 한 줄에 배치 |
| 본문·일반 안내 | `bodyCopyStyles`, 14–16px, 행간 1.7 |
| 보조 설명 | `captionStyles`, 12–14px. 안전·동의 설명을 고정 11px로 축소하지 않는다. |
| 입력 | `inputControlStyles`, 최소 16px, 내부 여백 14px, 둥글기 12px, 안쪽 포커스 표시 |

한 서체 안에서 역할과 여백으로 위계를 만든다. 제목 자간은 -0.025em을 기본으로 한다.
화면의 기본 좌우·상단 여백은 ScreenFrame에서 가져오며 앱 컨테이너와 safe area에 따라 조절한다.
책장은 전면 패딩을 없애더라도 헤더·도구에 같은 변수를 사용한다.
보기 선택은 현재 보기만 트리거에 표시하고 팝오버에서 한 권씩·표지·책등을 고른다.
선택 항목은 `menuitemradio`·`aria-checked`로 알리며 44px 조작 높이를 유지한다.
전체 마디·저장한 PDF·설정은 책장 상단 더보기에서 접근한다. 한 권씩은 책 미리보기를
남는 공간의 중앙에 두고 설명·넘김 행을 하단에 둔다.

## 색상과 조작

- 기본 진행·저장: 브랜드 파랑 배경 + 진한 파랑 글자. 밝은 파랑 위의 흰 작은 글자는 사용하지 않는다.
- 첫 화면의 짙은 파랑 CTA는 흰 글자를 명시하며 기본·호버 상태 모두 4.5:1 이상을 확보한다.
- 사진 선택·선택적 동의 등 문맥별 보조 강조: 연두 배경 + 진한 연두 글자.
- 보기 선택·이전/다음: 연한 파랑 바탕, 선택 상태는 흰 바탕과 명확한 글자.
- 파괴적 행동: 위험 색상과 확인 절차를 유지한다.
- 주 행동은 공용 PrimaryButton을 사용한다. 색상을 각 페이지에서 임의로 다시 덮지 않는다.
- 계층을 되돌아가는 버튼은 공용 BackButton/BackLink의 셰브론과 44px 조작 영역을 사용한다.
  돌아갈 목적지는 접근성 이름으로 제공하며 저장 중 보호·히스토리·닫기 애니메이션은 유지한다.
- 공통 키보드 포커스는 `--color-focus-ring`의 짙은 파랑을 사용한다. 밝은 파랑·연두·흰 바탕에서 구분한다.
  설정·알림 스위치는 기존 트랙 크기를 유지하되 라벨 누름 높이는 44px 이상이며 알림 시간 입력도 16px·44px를 따른다.

## 책과 앱 조작 UI의 경계

PDF 수치, A5 비율, 축소 표지·속지의 글자 크기는 인쇄/독서 레이아웃의 기준을 따른다.
앱 제목·필드 크기를 책 미니어처에 적용하거나 반대로 미니어처 글자 크기를 조작 UI에 적용하지 않는다.
책장 보기 3종과 함께 채우기, 페이지 넘김, 확대 전환은 유지한다.
한 권씩 보기는 저장된 선택이 없을 때 기본이며, 사용자의 기존 선택은 덮어쓰지 않는다.

## 검증 경계

타입·컴포넌트 렌더·브랜드 색상 대비·동작 테스트와 실제 렌더링 검증은 다르다.
브라우저/실기기에서 320px급 화면, 일반 휴대폰, PC 목업, 긴 제목, 빈 상태, 입력 중 키보드를 확인한다.
로컬 빌드는 하지 않으며 배포 산출물 빌드는 GitHub Actions에서 수행한다.

## 이번 적용 범위와 다음 순서

기본 보기, 공통 글자·필드·버튼, 책장과 주요 하위 화면의 기준을 먼저 적용했다.
마디 조회 실패/빈 상태를 분리하고 캐시가 있으면 목록을 유지하며 경량 재시도를 제공한다.
마디 스택에는 제스처 외에 이전·다음과 방향키 및 현재 위치 안내를 제공한다.
읽기/관리 도구 위계, 글 전용·사진 상세, 작성/수정 필드 및 주요 모달 표준도 코드에 반영했다.
다만 소스·동작 테스트와 실제 시각 검증은 구분한다. 320px급 화면·일반 휴대폰·PC 목업과
iOS·Android에서 긴 제목·공동작성·사진/글 전용·초안 복귀·중첩 모달을 확인해야 한다.
브라우저 엔진·실기기 렌더와 모션을 확인하기 전에는 시각 점검 완료로 기록하지 않는다.

## 모달 조작 기준

일반 공유·사진 위치 선택·웹 공개 동의·장소 검색·실물 제작 안내와 중요 확인창은 AppDialogFrame을 사용한다.
사진 맞추기도 같은 포커스·뒤로가기 기반을 사용하되 앱 영역을 채우는 작업 화면을 유지한다.
일반 작업은 dialog, 파괴적 행동의 중요 확인은 alertdialog로 구분한다.
PC에서도 앱 컨테이너 안에 표시하며 입력·링크를 포함해 포커스를 가두고 닫은 뒤 복귀한다.
겹쳐 열린 경우 맨 위 모달만 Escape와 Android 뒤로가기를 처리하고, 마지막 모달이 닫힐 때 배경 잠금을 해제한다.
출발 준비의 바텀시트·확장·뒤집기 화면도 같은 포커스 수명을 사용한다. 전환 레이어를
교체하지 않고 내부가 조작 가능해진 뒤 초점을 옮기며, 닫기 버튼·기존 히스토리·전환 시간을 유지한다.
저장 중 닫기는 차단한다. 사진 위치 선택을 닫는 것은 동의가 아니라 위치 없이 계속하기이며,
웹 공개는 기존의 명시적인 체크와 제출을 유지한다.

## 하루마디 읽기와 관리

읽기에서는 지면·쪽 이동·마디 남기기를 우선한다. 함께 채우기는 작성 옆에 계속 노출하고,
공유 책의 댓글·답글도 헤더에서 바로 연다. 이름과 표지·골라 담기·순서 변경·PDF 저장은
이름이 보이는 관리 메뉴에서 연다. 참여자에게 소유자 전용 설정·정렬을 제공하지 않는다.
읽기 전용 캐시나 저장 중에는 관리·작성·공동작성 진입을 잠근다.
책 펼침·쪽 넘김·덮기와 PDF 지면 자체는 이 도구 정리와 별개로 유지한다.
이름·표지·뒷표지·골라 담기·순서의 미저장 변경은 돌아가기 전에 확인한다. 저장 중 이탈 차단과
새로고침의 브라우저 경고를 유지하며 책 편집 초안의 영속 저장과 구분한다.
골라 담기는 썸네일·글 전용 단서·선택 수·날짜 묶음·검색을 제공하고 원문은 읽기 전용 미리보기로 확인한다.

## 마디 상세의 콘텐츠 유형

사진 없는 마디는 빈 이미지 블록 없이 날짜와 선택 제목·장소 및 본문으로 구성한다.
빈 제목·본문·미지정 장소는 공간만 차지하는 요소로 만들지 않는다.
사진이 있으면 작성 미리보기처럼 원본 구도가 보이도록 contain으로 표시한다.
글 전용 및 동작 줄이기에서는 사진 확대 전환을 시작하지 않으며, 이미지 대상이 없어 대기하지 않는다.
상세의 조회 실패도 찾을 수 없음과 구분하고 재시도를 제공한다.
인쇄 PDF 레이아웃과 사진 배치 정책은 이 상세 UI 변경 대상이 아니다.
전체 마디에서는 제목·이야기·장소·작성자·한국 날짜를 검색한다. 원본 순서를 유지하며 검색 결과 없음과
마디가 하나도 없음·조회 실패를 구분한다. 같은 검색 필드·로직을 골라 담기에서도 사용한다.

작은 여행의 더보기는 작은 여행 / 도움말·설정 / 운영(권한이 있을 때)으로 묶는다.
그룹 이름은 초점 이동 대상이 아니며 기존 동작과 권한 조건은 바꾸지 않는다.

작성·수정은 같은 필드 라벨과 안내 문구를 사용하며 제목 → 이야기 → 날짜 → 장소 순서로 입력한다.
혼자 쓰는 마디에도 자연스러운 문구를 사용하고 제목은 선택임을 표시한다.
수정의 날짜를 사진 위 작은 배지로 겹치지 않으며 공통 필드와 iOS 날짜 너비 규칙을 따른다.
사진 없는 수정 화면의 사진 추가는 작은 조작부로 제공하고, 선택한 사진의 원본 구도를 보여준다.
초안·날짜/장소 수동 변경 보호·수정 버전 충돌 검사·민감정보 동의 의미는 변경하지 않는다.

공동작성의 댓글 기능은 진입점·화면 제목·작성 버튼에서 댓글·답글로 명명한다.
공유 범위와 PDF 미포함 안내는 유지하고, 긴 참여자 이름과 장소는 좁은 화면에서도 줄바꿈한다.
제작 준비 안내의 관심 표시 계측과 재전송 기능도 모달 통합으로 바꾸지 않는다.

## 토스트

작은 여행의 밝은 표면을 ToastSurface로 공유한다. 흰 바탕·중립색 글자·14px 둥글기와
같은 그림자를 사용하고, 행동은 연두색 ToastAction, 닫기는 ToastDismiss를 사용한다.
공용 토스트만 짙은 녹색 바탕으로 따로 표시하지 않는다. 오류는 alert와 보조 아이콘으로 구분한다.
긴 안내와 명시적인 줄바꿈은 유지한다. 앱 목업 내부 위치·일반/오류 알림 수명·호버/포커스 일시정지와
작은 여행의 순차 안내·행동 버튼은 각각 기존 흐름을 유지하며 색상 통일을 위해 합치지 않는다.
