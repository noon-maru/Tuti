# Tuti 사용자 화면의 공통 디자인 규칙

나들이와 책장에 LINE Seed KR, 흰 바탕, 파랑·연두, 둥근 조작부를 공통 적용한다.
정체성을 교체하는 리디자인이 아니라 같은 앱의 조작 UI를 맞추는 기준이다.

책장 바탕은 `palette.surface.library`의 노란 기를 줄인 백색(`#FCFBFA`)을 쓰며 하단 내비게이션까지
같은 색으로 잇는다. 나들이·책 읽기·실제 흰 표지와 속지의 바탕은 변경하지 않는다.

## 기준 코드

- 역할별 CSS 변수: [GlobalStyles.tsx](../src/app/GlobalStyles.tsx)

## 글자와 공간

감성은 안내 문구나 정보량을 늘리는 대신 실제 사진·이야기와 여백으로 만든다.
검색·필터·보기 선택은 필요할 때 펼치고, 현재 조건을 바꿨을 때만 해제 조작을 표시한다.
‘나의 마디’는 검색을 아이콘으로 접고 제목의 펼침 메뉴에 필터·보기 방식을 모은다.
하단의 상시 이전·다음 버튼과 쪽수는 노출하지 않되 휠·스와이프·방향키와 보조기술용
이동·현재 위치 알림은 유지한다. 키보드로 이동 조작에 초점을 주면 조작부가 나타난다.
간결화 대상은 주변 조작부이며 핵심 콘텐츠인 마디 카드 자체가 아니다.
카드의 기존 겹침·색상·그림자·날짜·제목·본문·장소 표현은 유지한다.
설정은 중립적인 소제목과 단색 선 아이콘으로 묶고, 메뉴명을 반복하는 설명과 그룹 외곽 구분선은 덜어낸다. 위치·알림 범위와 기기 계정 연결처럼 판단에 필요한 안내, 스위치와 이동 경로는 유지한다.
마디 작성의 첫 선택 단계는 화면 높이에 맞춘 상단 여백으로 내용을 분산하되, 높이 620px 이하에서는 여백을 줄인다. 두 번째 단계는 사진 유무와 무관하게 작은 질문 제목을 쓰고 입력 간격을 20px로 맞춘다. 사진 비율·입력창 최소 크기·하단 저장 영역·초안 및 저장 흐름은 바꾸지 않는다.

| 역할 | 규칙 |
| --- | --- |
| 하위 화면 제목 | `screenTitleStyles`, 20–22px, 600, 행간 1.4 |
| 단계별 질문 | `sectionHeadingStyles`, 24–26px, 600 |
| 책장 홈 헤더 | 나의 마디·새 하루마디·검색·더보기를 한 줄에 배치하고 보기 방식은 더보기에 통합 |
| 본문·일반 안내 | `bodyCopyStyles`, 14–16px, 행간 1.7 |
| 보조 설명 | `captionStyles`, 12–14px. 안전·동의 설명을 고정 11px로 축소하지 않는다. |
| 입력 | `inputControlStyles`, 최소 16px, 내부 여백 14px, 둥글기 12px, 안쪽 포커스 표시 |

본문·입력·버튼·날짜·장소·기능 제목은 `--font-sans`(LINE Seed KR)를 쓴다.
대표 문구·빈 책장 제목·하루마디 제목에만 `--font-emotional`(나눔스퀘어라운드)를 쓴다.
모든 h1/h2를 일괄 교체하지 않는다. 운영 센터는 Pretendard, 공식 워드마크는 기존 자산을 유지한다.
정적 굵기·라이선스·PDF 적용은 [서체 기준](./pdf-fonts.md)을 따른다.
크기·역할·여백으로 위계를 만들며 제목 자간은 -0.025em을 기본으로 한다.
화면의 기본 좌우·상단 여백은 ScreenFrame에서 가져오며 앱 컨테이너와 safe area에 따라 조절한다.
책장은 전면 패딩을 없애더라도 헤더·도구에 같은 변수를 사용한다.
보기 선택은 상단 더보기의 ‘책장 보기’ 그룹에 통합하고 한 권씩·표지·책등을 고른다. 기본은 한 권씩이며 기존의 계정별 선택은 유지한다.
선택 항목은 `menuitemradio`·`aria-checked`로 알리며 44px 조작 높이를 유지한다.
책장 헤더는 나의 마디·새 하루마디·검색·더보기를 한 줄에 둔다.
검색은 헤더 위의 절대 위치 입력창으로 펼쳐 책과 설명을 밀지 않는다. 검색 중 기존 헤더는 숨기고 비활성화하며 닫기·Escape·검색 아이콘 포커스 복귀를 지원한다.
저장한 PDF·설정은 상단 더보기에서 접근한다. 한 권씩은 확대된 책 미리보기를
남는 공간의 중앙에 두고 설명·넘김 행을 하단에 둔다. 가로 일부는 잘려도 되지만
세로는 전시 영역 안에 맞춘다. 실제 하루마디·PDF 지면의 크기와 구성은 바꾸지 않는다.
저장한 PDF 화면은 공통 헤더·서체·흰색 바탕을 사용한다. 빈 상태는 중앙의 짧은 안내와 책장 복귀 행동으로 연결하고, 보관 방식 설명은 하단 접이식 안내로 둔다. 저장된 파일은 실제 표지와 제목·저장일·쪽수만 담은 2열 목록(넓은 화면 3열)으로 표시한다. 초기 조회와 실패를 빈 상태로 오인하지 않으며 추가 조회 실패에도 이미 보이는 파일을 유지한다.
PDF 저장 화면도 뒤로가기와 제목을 한 줄로 묶고, 보관 안내는 한 문장으로 줄여 지면에 공간을 준다. 확대·텍스트·전체화면 도구는 캡슐 테두리와 그림자 없이 표시하며 44px 터치 영역과 고정 도구 행을 유지한다. 생성·승인·민감정보 확인·저장 및 파일 내보내기 절차와 PDF 지면 자체는 변경하지 않는다.
마디가 담긴 하루마디의 마지막 쪽에서는 하단 작성·함께 채우기의 두 자리를 PDF로 저장하기·실물로 소장하기로 교체한다. 기존 파랑·연두 버튼의 역할과 배치를 이어받고 지면 아래에 행동이나 준비 안내 행을 중복 배치하지 않는다. 실물 소장의 준비 중 모달과 노출·클릭 계측은 유지한다. 관리 메뉴와 함께 채우기의 PDF 진입도 같은 준비 경로를 사용한다. 빈 책·읽기 전용 캐시·쪽 전환 중에는 교체하지 않으며 저장·닫기·열기 중에는 실행을 잠근다.
양끝 터치는 잘리기 전 책이 아닌 실제 보이는 영역을 기준으로 판정하며 짧은 좌우 스와이프도 허용한다.
책을 아래로 끌면 선택한 하루마디에 마디를 남긴다. 나들이의 아래로 끌어 작성하기와 방향을 맞추며, 위로 밀기·대각선·좌우 넘김을 작성으로 오인하지 않는다. 같은 동작의 버튼과 아래 방향 안내도 유지한다.
책장과 나들이의 아래로 끌어 작성하기는 같은 `MadiComposeRevealLayer`를 사용한다. 드래그 140px를 진행률 1로 삼아 투명도 0→1, 위쪽 34px→제자리로 드러낸다. 화면 전체 높이만큼 끌어오지 않는다. 책장에서 짧게 당기거나 취소하면 240ms 동안 사라지며, 진입을 확정하면 120ms 동안 남은 페이드·짧은 이동을 마무리한 뒤 실제 작성 화면에 연결한다. 동작 줄이기에서는 공간 이동을 없애고 책장 마무리 이동을 생략한다. 드래그 미리보기는 입력·초안 저장·활동 계측을 시작하지 않으며 실제 화면에 추가 진입 애니메이션을 중복 적용하지 않는다.
한 권씩 전시 영역의 좌우 12~20px는 책장 배경색으로 페이드해 잘림 경계를 완화한다. 시각 레이어는 클릭을 통과시키며 지면 중앙·헤더·하단 설명에는 적용하지 않는다. 키보드로 전시 영역을 선택한 동안은 포커스 테두리를 가리지 않도록 페이드를 숨긴다.
좌우 드래그는 첫 책·마지막 책과 한 권 간격을 넘어서도 저항을 점차 키우며 늘어나게 한다. 고정 거리에서 잘라 멈추지 않으며 놓으면 원점 또는 선택한 옆 책으로 복귀한다.
앞뒤 순서·크기·회전은 실제 존재하는 옆 책 한 권까지만 보간한다. 그 이상의 탄성 당김은 책 묶음 전체의 평행 이동으로만 표현해 다다음 책이 맨 앞으로 나오지 않게 한다.
드래그 중 현재 책은 앞에서 점진적으로 페이드아웃해 옆 책을 드러낸다. 중간 임계점에서 앞뒤 순서를 갑자기 뒤집지 않으며, 끝의 탄성 당김에는 페이드를 적용하지 않는다. 버튼 이동의 위치·페이드·쌓임 순서 전환은 같은 560ms 동안 진행한다.
미리보기는 닫힌 표지와 펼친 오른쪽 지면의 중심을 같은 자리에 고정한다. 두 쪽 전체를 중앙으로 재배치하지 않고 왼쪽 지면은 화면 밖으로 펼쳐져도 된다. 펼침·접힘에는 표지와 지면 회전만 쓰며 책 전체를 가로로 이동시키지 않는다.
마디가 0개면 오른쪽에 첫 마디 안내, 1개면 오른쪽에 첫 마디의 첫 지면을 놓고 왼쪽은 비운다. 책장과 확대 전환에 같은 배치를 쓰며 실제 읽기·PDF 페이지 순서는 바꾸지 않는다.
사진 없는 미리보기는 320px 조판 기준 본문 18px·마디 제목 20px·메타 12px와 진한 글자색을 사용한다. 미리보기 제목은 3줄·본문은 6줄까지만 노출하며 실제 읽기·PDF 원문과 조판은 유지한다. 책 아래 하루마디 제목은 `--font-size-300`으로 한 단계 낮춰 지면을 우선한다.
미리보기를 눌러 읽을 때는 현재 오른쪽 지면의 중심에서 1.25배 확대하고 읽기 화면으로 교차 전환한다. 두 쪽 전체를 화면 안에 맞추려고 축소하지 않으며 확대 중 넘치는 지면은 전환 레이어에서 자른다.

## 색상과 조작

책장 상단의 나의 마디·새 하루마디는 `compactSecondaryButtonStyles`로 44px 높이·같은 글자와 여백·옅은 파랑 배경을 공유한다.
검색·닫기·상단/책별 더보기·이전/다음은 `quietIconButtonStyles`로 44px 조작 영역·20px 아이콘·투명 배경과 같은 호버/누름/포커스/비활성 상태를 쓴다.
하단 마디 남기기는 주 행동으로 더 강한 강조를 유지한다. 책 지면과 미리보기의 크기·배치는 버튼 정리에서 변경하지 않는다.

- 기본 진행·저장: 브랜드 파랑 배경 + 진한 파랑 글자. 밝은 파랑 위의 흰 작은 글자는 사용하지 않는다.
- 첫 화면의 짙은 파랑 CTA는 흰 글자를 명시하며 기본·호버 상태 모두 4.5:1 이상을 확보한다.
- 사진 선택·선택적 동의 등 문맥별 보조 강조: 연두 배경 + 진한 연두 글자.
- 보기 선택·이전/다음: 연한 파랑 바탕, 선택 상태는 흰 바탕과 명확한 글자.
- 파괴적 행동: 위험 색상과 확인 절차를 유지한다.
- 주 행동은 공용 PrimaryButton을 사용한다. 색상을 각 페이지에서 임의로 다시 덮지 않는다.
- 계층을 되돌아가는 버튼은 공용 BackButton/BackLink의 셰브론과 44px 조작 영역을 사용한다.
  돌아갈 목적지는 접근성 이름으로 제공하며 저장 중 보호·히스토리·닫기 애니메이션은 유지한다.
- 공통 키보드 포커스는 `--color-focus-ring`의 짙은 파랑을 사용한다. 밝은 파랑·연두·흰 바탕에서 구분한다.
  설정·알림 스위치는 기존 트랙 크기를 유지하되 라벨 누름 높이는 44px 이상이며 알림 시간 입력도 16px·44px를 따른다.

## 책과 앱 조작 UI의 경계

PDF 수치, A5 비율, 축소 표지·속지의 글자 크기는 인쇄/독서 레이아웃의 기준을 따른다.
앱 제목·필드 크기를 책 미니어처에 적용하거나 반대로 미니어처 글자 크기를 조작 UI에 적용하지 않는다.
책장 보기 3종과 함께 채우기, 페이지 넘김, 확대 전환은 유지한다.
한 권씩 보기는 저장된 선택이 없을 때 기본이며, 사용자의 기존 선택은 덮어쓰지 않는다.

## 검증 경계

타입·컴포넌트 렌더·브랜드 색상 대비·동작 테스트와 실제 렌더링 검증은 다르다.
브라우저/실기기에서 320px급 화면, 일반 휴대폰, PC 목업, 긴 제목, 빈 상태, 입력 중 키보드를 확인한다.
로컬 빌드는 하지 않으며 배포 산출물 빌드는 GitHub Actions에서 수행한다.

## 이번 적용 범위와 다음 순서

기본 보기, 공통 글자·필드·버튼, 책장과 주요 하위 화면의 기준을 먼저 적용했다.
마디 조회 실패/빈 상태를 분리하고 캐시가 있으면 목록을 유지하며 경량 재시도를 제공한다.
마디 스택에는 제스처 외에 이전·다음과 방향키 및 현재 위치 안내를 제공한다.
읽기/관리 도구 위계, 글 전용·사진 상세, 작성/수정 필드 및 주요 모달 표준도 코드에 반영했다.
다만 소스·동작 테스트와 실제 시각 검증은 구분한다. 320px급 화면·일반 휴대폰·PC 목업과
iOS·Android에서 긴 제목·공동작성·사진/글 전용·초안 복귀·중첩 모달을 확인해야 한다.
브라우저 엔진·실기기 렌더와 모션을 확인하기 전에는 시각 점검 완료로 기록하지 않는다.

## 모달 조작 기준

일반 공유·사진 위치 선택·웹 공개 동의·실물 제작 안내와 중요 확인창은 AppDialogFrame을 사용한다.
마디 장소 검색은 입력창 위 오버레이로 제공한다. 개인 장소는 입력창에 가까운 하단,
일반 장소는 상단에 두며 폼 레이아웃을 밀지 않는다. PC 목업·키보드 가용 영역에 맞춰 높이를 제한한다.
사진 맞추기도 같은 포커스·뒤로가기 기반을 사용하되 앱 영역을 채우는 작업 화면을 유지한다.
일반 작업은 dialog, 파괴적 행동의 중요 확인은 alertdialog로 구분한다.
PC에서도 앱 컨테이너 안에 표시하며 입력·링크를 포함해 포커스를 가두고 닫은 뒤 복귀한다.
겹쳐 열린 경우 맨 위 모달만 Escape와 Android 뒤로가기를 처리하고, 마지막 모달이 닫힐 때 배경 잠금을 해제한다.
출발 준비의 바텀시트·확장·뒤집기 화면도 같은 포커스 수명을 사용한다. 전환 레이어를
교체하지 않고 내부가 조작 가능해진 뒤 초점을 옮기며, 닫기 버튼·기존 히스토리·전환 시간을 유지한다.
저장 중 닫기는 차단한다. 사진 위치 선택을 닫는 것은 동의가 아니라 위치 없이 계속하기이며,
웹 공개는 기존의 명시적인 체크와 제출을 유지한다.

## 하루마디 읽기와 관리

하단 내비게이션의 표시명은 **책장 · 마디 남기기 · 나들이**로 고정한다. 첫 작성 유도는 빈 상태와
소개 화면에서 제공하고 하단 버튼 이름은 바꾸지 않는다. 화면 진입·질문·복귀 안내도 나들이로 맞추되,
콘텐츠 이름인 하루마디와 브랜드 철학·과거 문맥의 작은 여행은 별개로 유지한다. 경로와 분석 이벤트 ID는 변경하지 않는다.

책장과 작은 여행의 상단 더보기는 공통 `MainMenu`를 사용한다. 세로 점 3개·44px 원형 조작 영역과
hover·키보드 포커스를 공유하며, 화면별 동작 다음에 도움말·앱 다운로드(웹)·설정·관리자 메뉴(앱 제외)를 같은 순서로 둔다.
관리자 항목은 현재 계정의 관리자 역할이 확인된 경우에만 표시한다. 책장은 보관함과 하루마디 예시,
작은 여행은 조건 변경·재추천·저장 장소·튜토리얼을 제공한다. 개별 책·마디의 관리 메뉴와는 별개다.

읽기에서는 지면·쪽 이동·마디 남기기를 우선한다. 함께 채우기는 작성 옆에 계속 노출하고,
공유 책의 댓글·답글도 헤더에서 바로 연다. 하루마디 꾸미기·골라 담기·순서 변경·PDF 저장은
이름이 보이는 관리 메뉴에서 연다. 참여자에게 소유자 전용 설정·정렬을 제공하지 않는다.
읽기 전용 캐시나 저장 중에는 관리·작성·공동작성 진입을 잠근다.
책 펼침·쪽 넘김·덮기와 PDF 지면 자체는 이 도구 정리와 별개로 유지한다.
이름·표지·뒷표지·골라 담기·순서의 미저장 변경은 돌아가기 전에 확인한다. 저장 중 이탈 차단과
새로고침의 브라우저 경고를 유지하며 책 편집 초안의 영속 저장과 구분한다.
골라 담기는 썸네일·글 전용 단서·선택 수·날짜 묶음·검색을 제공하고 원문은 읽기 전용 미리보기로 확인한다.

## 마디 상세의 콘텐츠 유형

사진 없는 마디는 빈 이미지 블록 없이 날짜와 선택 제목·장소 및 본문으로 구성한다.
빈 제목·본문·미지정 장소는 공간만 차지하는 요소로 만들지 않는다.
사진이 있으면 작성 미리보기처럼 원본 구도가 보이도록 contain으로 표시한다.
글 전용 및 동작 줄이기에서는 사진 확대 전환을 시작하지 않으며, 이미지 대상이 없어 대기하지 않는다.
상세의 조회 실패도 찾을 수 없음과 구분하고 재시도를 제공한다.
인쇄 PDF 레이아웃과 사진 배치 정책은 이 상세 UI 변경 대상이 아니다.
전체 마디에서는 제목·이야기·장소·작성자·한국 날짜를 검색한다. 원본 순서를 유지하며 검색 결과 없음과
마디가 하나도 없음·조회 실패를 구분한다. 같은 검색 필드·로직을 골라 담기에서도 사용한다.

작은 여행의 더보기는 작은 여행 / 도움말·설정 / 운영(권한이 있을 때)으로 묶는다.
그룹 이름은 초점 이동 대상이 아니며 기존 동작과 권한 조건은 바꾸지 않는다.

작성·수정은 같은 필드 라벨과 안내 문구를 사용하며 제목 → 이야기 → 날짜 → 장소 순서로 입력한다.
혼자 쓰는 마디에도 자연스러운 문구를 사용하고 제목은 선택임을 표시한다.
수정의 날짜를 사진 위 작은 배지로 겹치지 않으며 공통 필드와 iOS 날짜 너비 규칙을 따른다.
사진 없는 수정 화면의 사진 추가는 작은 조작부로 제공하고, 선택한 사진의 원본 구도를 보여준다.
사진·장소를 빼는 조작은 다른 필드를 지우지 않는다. 장소 직접 입력과 선택 검색은 작성·수정에서
같은 입력기를 사용한다. 지정 책의 제목·공유 범위를 작성 중과 최종 저장 행동 가까이에 표시한다.
필드 검증 안내는 입력과 접근성 설명으로 연결하고, 아직 다루지 않은 빈 필드는 중립 안내로 둔다.
초안·날짜/장소 수동 변경 보호·수정 버전 충돌 검사·민감정보 동의 의미는 변경하지 않는다.

공동작성의 댓글 기능은 진입점·화면 제목·작성 버튼에서 댓글·답글로 명명한다.
공유 범위와 PDF 미포함 안내는 유지하고, 긴 참여자 이름과 장소는 좁은 화면에서도 줄바꿈한다.
제작 준비 안내의 관심 표시 계측과 재전송 기능도 모달 통합으로 바꾸지 않는다.

## 토스트

작은 여행의 밝은 표면을 ToastSurface로 공유한다. 흰 바탕·중립색 글자·14px 둥글기와
같은 그림자를 사용하고, 행동은 연두색 ToastAction, 닫기는 ToastDismiss를 사용한다.
공용 토스트만 짙은 녹색 바탕으로 따로 표시하지 않는다. 오류는 alert와 보조 아이콘으로 구분한다.
긴 안내와 명시적인 줄바꿈은 유지한다. 앱 목업 내부 위치·일반/오류 알림 수명·호버/포커스 일시정지와
작은 여행의 순차 안내·행동 버튼은 각각 기존 흐름을 유지하며 색상 통일을 위해 합치지 않는다.
