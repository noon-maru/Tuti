# Tuti 위치정보 보호조치 자체점검표

## 사용 방법

- 정기점검은 매년 8월 15일까지, 권한·보존 점검은 반기마다 실시한다.
- 자동 점검 명령의 결과와 이 문서의 작성본을
  `.compliance-evidence/location-security/`에 함께 보관한다.
- `적합`, `개선 필요`, `해당 없음` 중 하나를 표시하고 개선 필요 항목에는
  담당자와 완료기한을 반드시 기록한다.
- 자동 점검은 사람의 계약·권한·사고 대응 판단을 대신하지 않는다.
