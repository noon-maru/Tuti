# 향후 검토 사양

이 문서는 **구현 확정이나 현재 제공 기능을 뜻하지 않는다.** 실제 개발을 결정하면
각 기능의 요구사항·동의·운영 기준을 별도로 검증하고 해당 현행 문서에 반영한다.

## 추천 장소 3×3 모아보기

상태: 테스터 요청에 따른 검토 후보, 구현 확정 아님. 기본 화면은 현재의 카드
경험으로 유지한다. 여러 장소를 비교하거나 이전 카드로 돌아가기 어렵다는 점을
보완할 선택형 보기 방식이다.

- 같은 일일 추천 결과와 순서를 카드 화면과 공유한다. 9칸을 채우려고 장소를
  반복하거나 품질 기준을 낮추지 않는다.
- 대표 이미지와 장소를 구별하는 최소 정보만 표시한다. 선택한 장소는 기존
  상세·출발 준비 흐름으로 연결하고, 돌아왔을 때 스크롤·선택 상태를 복원한다.
- 좁은 화면, 폴드 펼침 화면, 태블릿에서 열 수와 터치 영역을 검증한다.
  이미지 지연 로딩, 키보드 포커스, 스크린리더 순서와 제스처 안내도 함께 점검한다.
- 제한 시험에서 첫 장소 선택까지의 시간, 이탈률, 상세·길찾기 전환 및
  결정 피로에 관한 피드백을 기존 카드 화면과 비교한다. 열람량만 늘고
  출발 행동이 줄면 채택하지 않는다.

## 공개 기록의 사후 AI 안전 분류

상태: 검토 후보. 공개 전 관리자 승인을 다시 도입하지 않는다. 도입한다면
신고 대응의 우선순위를 정하는 보조 수단으로만 사용한다.

- 개인정보·연락처·외부 유도, 혐오·위협·성적 착취·스팸 의심 신호를 분류한다.
- 높은 위험 신호는 운영자에게 알리되 모델 판단만으로 원본 기록을 영구 삭제하거나
  계정을 영구 제재하지 않는다.
- 오탐·누락, 처리 지연, 이의제기 결과를 검증하고 모델·정책 버전과 필요한
  최소 판정 근거만 감사 기록에 남긴다.
- 기록 본문을 외부 모델에 보내기 전 개인정보 처리방침, 외부 처리와 보존기간,
  사용자 고지·선택을 별도로 검토한다. 취향 개인화 동의를 안전 분류 동의로
  간주하지 않는다.

## 종료된 공개 링크 안내

상태: 검토 후보. 현재 공개 중지·숨김·삭제된 링크는 404로 처리한다.

- 향후 `공개가 끝난 기록이에요`라는 안내 화면과 홈·공개 운영정책 이동을
  제공할 수 있다.
- 존재한 적 없는 주소와 종료된 주소를 응답 코드나 공개 API만으로 구별할 수
  없게 하고, 제목·장소·작성자·이미지 등 과거 공개 내용을 다시 노출하지 않는다.
