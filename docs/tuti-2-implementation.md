# Tuti 2.0 구현 진행

기준: 2026-11-17. [브랜드 정의서](./brand-definition.md)와 [핵심 타깃·설계 원칙 v1.1](./target-and-design-principles.md)을 따른다. 구현·시험과 운영 배포·실기기 검증은 구분한다.

## 기록·재열람과 외출 연결

- 첫 화면은 반려동물과 살아가는 기록이라는 고객 설명과 기존 첫 마디 작성 경로를 함께 유지한다. 프로필·책 생성을 작성 조건으로 추가하지 않는다.
- 읽는 책의 관리 메뉴에서 `다음에 보낼 하루 찾아보기`로 이동한다. 계정과 선택 책 ID를 함께 전달하며, 작성 시 기존 서버 권한·공유 범위 재검증을 유지한다.
- 추천 장소의 작성 버튼과 출발 후 이어 남기기에 선택 책을 전달한다. 장소는 편집 가능한 제안이며 방문을 자동 확정하지 않는다.
- 책장은 현재 계정에 속한 출발 의도만 안내한다. 출발 후 안내 시각이 지났고 7일 이내인 경우에만 표시하며 나중에로 미룰 수 있다. 과거 계정 정보가 없는 상태는 책장 안내에 사용하지 않는다.
- 저장 후 책에 담은 결과에서 `방금 남긴 쪽 보기`를 제공한다. `focusEntryId`는 읽기 위치일 뿐 연결 추가·방문 생성·접근 허용을 실행하지 않는다.

## 동반 조건·선택 프로필 구현

[상세 동작·권한·자료 입력·배포 순서](./pets-and-dog-outings.md)를 따른다. 동반 조건 테이블·조회·후보 필터와 선택 프로필 등록·수정·삭제·마디 연결 UI/API를 추가했다.
프로필과 연결은 계정 병합·파기·삭제 복원 방지 원장과 함께 처리한다. 세 추가형 마이그레이션을 개발 DB에 적용했으며 운영에는 적용하지 않았다.
국문 API를 기본 원본으로 사용한다. 개발 DB에 공식 동반 원문 9,634건을 입력하고 기존 장소 779곳과 연결했다.
일반 추천 후보 기준을 통과한 269곳 중 예시 동반 조건(8kg·목줄 착용·이동장 미사용)에서는 239곳이 포함됐다.
공식 등록의 미확인 조건은 방문 전 확인 필요로 표시하며 운영자 검토 자료·수집일·시설 확인일을 구분한다.
미매칭 원문으로 신규 장소를 자동 승인하거나 일반 장소를 동반 가능으로 임의 전환하지 않는다.

## 남은 검증·확장 범위

1. 대표 이미지·이용 방법·책장 진입점의 전체 정합성과 첫 작성·다른 시점 재열람 UX를 실기기로 검증한다. 하단 내비게이션 위계 재설계는 아직 적용하지 않았다.
2. 후보 저장 후 재진입 등 모든 외출 경로의 선택 책 맥락을 연결하고, 기록 전용·연결 이용 계측을 구분한다.
3. 공식 원문 매칭 범위 확대와 동반 모드의 지역별 후보·자료 신선도·조건 노출을 운영 전에 확인한다. 일반 장소 모드는 별도로 유지한다.
4. 추가형 마이그레이션·실제 DB 경계·백업 복원과 iOS/Android 실기기 UI를 검증한다. 프로필 사진·공동 프로필 관리·기존 마디의 연결 편집 UI는 후속 범위다.

속지 선택과 실물 결제·제작·배송은 이번 구현의 선행 조건이 아니다. 기존 마디·책을 새 타깃에 맞춰 자동 변환하거나 삭제하지 않는다.
