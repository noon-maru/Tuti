# Tuti 2.0 구현 진행

기준: 2026-11-16. [브랜드 정의서](./brand-definition.md)와 사용자가 제공한 핵심 타깃·설계 원칙 v1.1을 따른다. 구현·시험과 운영 배포·실기기 검증은 구분한다.

## 기록·재열람과 외출 연결

- 첫 화면은 반려동물과 살아가는 기록이라는 고객 설명과 기존 첫 마디 작성 경로를 함께 유지한다. 프로필·책 생성을 작성 조건으로 추가하지 않는다.
- 읽는 책의 관리 메뉴에서 `다음에 보낼 하루 찾아보기`로 이동한다. 계정과 선택 책 ID를 함께 전달하며, 작성 시 기존 서버 권한·공유 범위 재검증을 유지한다.
- 추천 장소의 작성 버튼과 출발 후 이어 남기기에 선택 책을 전달한다. 장소는 편집 가능한 제안이며 방문을 자동 확정하지 않는다.
- 책장은 현재 계정에 속한 출발 의도만 안내한다. 출발 후 안내 시각이 지났고 7일 이내인 경우에만 표시하며 나중에로 미룰 수 있다. 과거 계정 정보가 없는 상태는 책장 안내에 사용하지 않는다.
- 저장 후 책에 담은 결과에서 `방금 남긴 쪽 보기`를 제공한다. `focusEntryId`는 읽기 위치일 뿐 연결 추가·방문 생성·접근 허용을 실행하지 않는다.

## 남은 구현 범위

1. 대표 이미지·이용 방법·책장 진입점의 전체 정합성과 첫 작성·다른 시점 재열람 UX를 실기기로 검증한다. 하단 내비게이션 위계 재설계는 아직 적용하지 않았다.
2. 후보 저장 후 재진입 등 모든 외출 경로의 선택 책 맥락을 연결하고, 기록 전용·연결 이용 계측을 구분한다.
3. 반려견 동반 정보의 출처·확인일·허용 구역·제약을 저장·검토하는 경로와 충족/불충족/미확인 추천 처리를 구현한다. 현재 일반 추천을 동반 가능 추천으로 홍보하지 않는다.
4. 선택 반려동물 프로필과 마디의 0~N 연결, 프로필 삭제와 원본 기록 보존, 계정 병합·파기·원장·캐시 처리를 구현한다. 프로필은 기록의 부모나 공유 권한이 아니다.

속지 선택과 실물 결제·제작·배송은 이번 구현의 선행 조건이 아니다. 기존 마디·책을 새 타깃에 맞춰 자동 변환하거나 삭제하지 않는다.
