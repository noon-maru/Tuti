# Tuti 2.0 제공 범위와 배포 기록

기준: 2026-11-20. 고객·브랜드 판단은 [브랜드 정의서](./brand-definition.md)와
[핵심 타깃·설계 원칙](./target-and-design-principles.md)을 따른다.
이 문서는 현재 제공 범위와 배포 증거의 입구다. 기능별 세부 사양을 중복 관리하지 않는다.

## 배포 상태

| 구분 | 확인된 상태 |
| --- | --- |
| main 통합 | `feat/dog-outing-engine-v2`를 fast-forward 통합 |
| 운영 서버 | 2026-11-19 `f475ef8a1c72` 배포, 공개 readiness·DB·객체 저장소 정상 |
| 작업 컨테이너 | 유지보수·보관·복원 워커 3개를 같은 운영 릴리스로 갱신 |
| 운영 DB | 11월 16~19일 추가형 마이그레이션 7개 적용, 총 105개 |
| 공개 장소 | 국문 동반 원문 9,634건 반영, 추천 준비 9,235곳. 전체 백업 후 공개 자료만 입력 |
| 네이티브 앱 | `2.0.0 (22)`, 앱 소스 `0a521e75`. 2026-11-19 양 스토어 업로드 성공 |
| 스토어 배포 | 2026-11-20 운영자 완료 확인. 공개 시각·국가별 전파·심사 상세는 별도 조회하지 않음 |

앱 소스에는 서버 배포 뒤의 버전 갱신과 앱 빌드용 공용 추천 타입 분리가 포함된다.
앱과 서버의 SHA가 같을 필요는 없다. 배포 이력은 현재 서버 설정이나 모든 단말의 업데이트를 보증하지 않는다.

## 현재 제공 경험

| 영역 | 범위·기준 문서 |
| --- | --- |
| 첫 이용 | 소개·예시 → 첫 마디/나들이 선택 → 명시적 약관 동의 → 선택 프로필 등록/건너뛰기 → 원래 행동. [프로필·첫 시작](./pets-and-dog-outings.md#첫-시작) |
| 마디 | 사진만·글만·사진과 글, 선택 제목·날짜·장소·반려동물 연결, 계정별 초안, 수정·삭제. [작성·보관](./madi.md) |
| 책장·하루마디 | 한 권씩 기본, 표지·책등 선택, 이름 검색, 읽던 곳, 표지·속지 색상, 순서 편집. [하루마디](./harumadi.md) |
| 함께 채우기 | 책 단위 초대·참여·댓글/답글·나가기·내보내기·전체 종료. [공유 범위와 소유권](./harumadi-together.md) |
| 소장 | 서버 PDF 보관·파일 내보내기, 실물 소장 관심 안내. 실제 주문·결제·배송은 없음 |
| 반려동물 | 선택 프로필·사진·마디 연결, 수정·삭제와 계정 병합·파기 통제. 공동 프로필 관리는 없음 |
| 나들이 | 명시적 동반 답변에 따른 후보·검색 범위, 조건 필터, 방문 전 확인, 위치 변화/명시적 재추천에 따른 목록 갱신. [현행 정책](./dog-outing-v2-policy.md) |
| 행동 연결 | 책에서 나들이 찾기·장소에서 작성·나중에 남기기·저장 후 방금 쓴 쪽으로 복귀. [행동 루프](./recommendation-action-loop.md) |
| 운영 센터 | 제품 가치와 처리 업무 분리, 재열람·리텐션·활성 시간, 나들이 품질·지원 진단. [운영 센터](./admin-console.md) |

반려동물 등장·등록·외출·매일 작성을 필수 조건으로 삼지 않는다.
기존 계정·마디·책을 새 고객군에 맞춰 삭제·자동 분류·변환하지 않는다.
화면의 서체·여백·색·모션은 [공통 UI 규칙](./ui-design-system.md)을 단일 기준으로 삼는다.

## 확인 근거와 남은 검증

- [운영 소스 CI](https://github.com/noon-maru/Tuti/actions/runs/44469046565): 전체 회귀·린트·웹 빌드·PostgreSQL 17 검증 통과.
- [운영 배포](https://github.com/noon-maru/Tuti/actions/runs/44469058280): NAS 이미지 전체 테스트·카탈로그 준비 검사·전체 백업·DB 단계·앱 교체·readiness 통과.
- 운영 공개 좌표 4지역×3시간 조건의 추천 회귀 통과. 후보가 부족한 지역은 4~5곳을 반환했고 수를 채우려고 조건을 풀지 않았다.
- [앱 소스 CI](https://github.com/noon-maru/Tuti/actions/runs/44488825373), [Android 업로드](https://github.com/noon-maru/Tuti/actions/runs/44488921222), [iOS 업로드](https://github.com/noon-maru/Tuti/actions/runs/44488919159) 통과.
- 자동 시험·업로드·운영자 배포 확인은 모든 실기기의 키보드·권한·공유·업그레이드 검증이나 실제 시설 이용 성공을 대신하지 않는다.

후속 검증은 첫 작성·다른 날짜 재열람, 실제 다중 계정 공동작성, 기기 권한·복귀,
지역·목적별 추천 만족과 원문 신선도에 집중한다. 현재 공급량과 개발 표본을 혼합하지 않는다.
[추천 검증 기록](./dog-outing-verification.md), [출시 문안·업로드 이력](./release-notes.md)을 함께 본다.

공동 반려동물 관리·자동 개체 인식·건강 관리·실물 주문은 후속 검토 범위다.
표지/속지 색상과 프로필 사진·기존 마디 연결 편집은 이미 제공하므로 미구현 목록에 넣지 않는다.
