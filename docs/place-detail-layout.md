# 작은 여행 장소 상세 레이아웃

2026-11-17. 기존 감성을 유지하면서 사진 이외의 본문 레이아웃을 재구성한 개발 기준이다.

## 방향과 범위

- 목적: 분위기를 살펴보고, 반려견과 방문할 조건을 확인한 뒤 외출 또는 마디 작성으로 이어진다.
- 기존 시각 언어: 흰 바탕, Pretendard, 짙은 파랑의 조작부, 연두색의 가벼운 강조를 유지한다.
- 사진·갤러리·확대 보기, 시트 드래그·확장·닫기·뒤로가기 처리는 기존 구현을 보존한다.
- 별도 추천 이유 카드와 작은 사실 카드 묶음 대신 본문 한 흐름으로 읽는다.

## 읽기 순서

1. 장소명·지역·짧은 문구와 이동 시간: 상단에서 장소 맥락을 확인한다.
2. 소개: 저장된 요약을 우선하고 없으면 원문 미리보기, 기본 설명 순서로 표시한다.
3. 반려견 동반 구역·제한·준비물: 정보가 있는 경우 상세의 핵심 판단 항목으로 보여준다.
4. 함께 보낼 시간: 저장된 체험 안내가 있을 때만 표시한다. 시설이나 활동을 추정해 만들지 않는다.
5. 가기 전에: 주소·운영·휴무·요금·체류·주차와 저장된 예약·문의 정보를 행으로 읽는다.
   긴 값은 자르지 않고 줄바꿈한다. 미기재·오래된 정보는 확인 필요로 구분한다.
6. 추가 사진과 길찾기·마디 남기기: 기존 갤러리를 유지하고 다음 행동을 한 구역에 모은다.
7. 원문·정보 출처: 긴 소개, 홈페이지 안내, 혼잡도·날씨의 출처/한계와 수집일을 접어둔다.

## 동작과 안전성

- 실패 시 남아 있는 장소 정보는 유지하고 상세 재시도를 제공한다. 조회 중에는 운영 정보를 지어내지 않는다.
- 길찾기는 유효한 목적지 좌표가 있을 때만 제공한다. 사용자 현재 좌표를 링크에 추가하지 않는다.
- 마디 작성은 기존 콜백을 유지해 선택된 장소와 하루마디 맥락을 넘긴다.
- 본문은 시트의 기존 스크롤을 사용하고 안쪽에 별도 세로 스크롤을 만들지 않는다.
- 원문·동반 안내의 `summary`는 버튼·링크처럼 드래그 대상에서 제외해 클릭·터치와 시트 이동이 충돌하지 않게 한다.
- 원문은 텍스트로 출력한다. HTML을 실행하거나 미확인 동반 조건을 허용으로 바꾸지 않는다.
- 작은 화면의 정보 행은 한 열로 바뀌며 조작부는 최소 44px, 길찾기·작성은 50px 이상이다.

실제 모바일에서의 균형과 드래그·사진 전환 체감은 별도 시각 검증이 필요하다. 코드 및 정적 렌더링 검증은
시설 이용 성공이나 실기기 검증 완료를 의미하지 않는다.

검증: 관련 28개 시험·TypeScript·ESLint·문서 링크 검사 통과. 사진·갤러리·기존 제스처/히스토리 코드는
변경 전과 비교했다. 독립 코드 검토에서 발견한 접기 조작과 드래그의 충돌을 수정하고 재검토했다.
브라우저 캡처 도구가 없어 코드 범위의 검토만 완료했으며 시각·실기기 승인을 주장하지 않는다.
