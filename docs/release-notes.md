# Tuti 스토어 출시 노트

Android의 `출시 노트`와 iOS의 `이 버전에서 업그레이드된 사항`은 같은 원문을
사용한다. 플랫폼마다 실제 제공 기능이 다르거나 한쪽에만 적용되는 긴급 수정이
있는 경우에만 문구를 분리하고, 그 사유를 해당 버전 아래에 함께 기록한다.

## 1.7.1

- 버전명: `1.7.1`
- Android 버전 코드 / iOS 빌드 번호: `21`
- 작은 여행의 기본 조건(한 시간 안에·차 없이), 자동 재확인 7일 간격, 새로움 가점과 익숙함 표시·취소를 포함한다. 기존 답변은 유지하며 메뉴에서 조건을 직접 바꿀 수 있다.
- iOS 앱 하단은 안전 영역을 보존하고 추가 여백만 4px에서 0px로 줄인다. Android·웹의 추가 여백은 바꾸지 않는다.
- 새로움 가점은 후보를 제거하지 않으며 사용자 입력·기존 추천 노출·본인 마디의 장소 ID만 내부 비교한다. 표시 취소·180일 만료·계정 삭제 및 승인 병합 처리를 구현했고 본문·사진을 외부 AI로 보내지 않는다. 신규 OS 권한·SDK·결제를 추가하지 않는다.
- 카페 분류와 문구 보강 코드는 포함하지만, 검토 잠금 중인 신규 카페 12곳이 운영에 공개됐다고 홍보하지 않는다.
- 2026-11-13 서버 `5d6d512`의 [운영 배포](https://github.com/noon-maru/Tuti/actions/runs/43376110470)와 `20261113010000_place_familiarity` 마이그레이션을 완료했다. 공개 readiness의 새 릴리스·DB·객체 저장소 정상과 운영 워커 3개의 갱신을 확인했다.
- App Store Review 스킬과 [Apple 지침](https://developer.apple.com/app-store/review/guidelines/)의 완성도·정확한 문구·개인정보 경계를 변경 범위에서 대조했다. 기존 위치 동의·계정 삭제·공유 보호는 유지한다. 실기기 검증·스토어 개인정보 신고의 실제 입력 상태·심사 승인을 대신하는 검토는 아니다.
- 빌드·Google Play 내부 테스트·App Store Connect 업로드는 Actions에서 수행한다. 심사 제출·정식 공개·최신/최소 지원 버전 환경변수 변경은 별도다.

### 공통 출시 노트

Tuti 1.7.1에서는 다음 마디가 될 작은 여행을 더 편하게 찾을 수 있도록 다듬었어요.

• 덜 본 장소를 먼저 제안하되, 익숙한 장소도 추천에서 사라지지 않아요.
• 작은 여행 메뉴에서 익숙한 장소를 표시하거나 취소할 수 있어요. 다음 추천에 반영돼요.
• 처음에는 ‘한 시간 안에·차 없이’로 가볍게 시작하고, 조건은 매일 다시 묻지 않아요. 원할 때 메뉴에서 바꿀 수 있어요.

### iOS 프로모션 텍스트

가까운 곳에서 다음 마디가 될 하루를 만나보세요. 익숙한 장소는 표시하고, 덜 본 장소부터 가볍게 둘러볼 수 있어요. 사진 한 장과 짧은 이야기로 오늘을 하루마디에 모아보세요.

프로모션·iOS 출시 문구는 App Store Connect 입력용이며 바이너리 업로드로 자동 갱신되지 않는다.

### iOS 심사 메모 보충

작은 여행 상단 메뉴의 `이 장소 → 익숙한 곳이에요`에서 본인에게 익숙한 장소를 표시하고 같은 자리에서 취소할 수 있다. 현재 카드는 유지하며 다음 새 추천 요청부터 덜 본 장소를 우선 제안한다. 계정별 표시를 180일간 저장하고 취소·계정 삭제 시 제거한다. 기존 기록의 본문·사진 분석이나 외부 AI 전송, 새 OS 권한은 추가하지 않는다. 실물 제작은 이전 버전과 같은 관심 표시이며 실제 주문·결제·배송 기능은 제공하지 않는다.

## 1.7.0

- 사진 중심 작성·선택적 맞추기, 마디 목록/미담기 필터와 담기, 읽던 마디 수정 복귀, 장소 상세의 작성 연결을 포함한다.

- PDF의 Tuti 보관과 기기 전달·취소를 구분하고, 내용이 있는 책의 마지막 쪽에서도 실물 관심 안내를 연다. 실제 주문·결제·배송은 제공하지 않는다.
- App Store Review 스킬 점검 범위는 변경 기능·버전·출시 문구와 기존 권한/공유 보호다. 새 OS 권한·SDK·외부 결제는 추가하지 않는다. 실물 준비 안내는 주문 기능이 아닌 관심 표시이며, 심사 메모에도 미제공 범위를 설명한다. 준비 중 기능의 노출에 대한 심사 위험과 실기기 검증은 남아 있고 심사 승인을 보증하지 않는다.
- 빌드·업로드는 Actions에서 수행한다. 운영 배포·마이그레이션·스토어 처리 결과는 확인 후 별도로 기록한다. 정식 공개와 최소 지원 버전 환경변수 변경은 자동 수행하지 않는다.
- 2026-11-11 소스 `c93f805`의 [전체 CI](https://github.com/noon-maru/Tuti/actions/runs/42983278206) 통과 후 [운영 배포](https://github.com/noon-maru/Tuti/actions/runs/42984085957)를 완료했다. 선택 기간 마이그레이션 적용과 공개 readiness의 `c93f80540b4b`, DB·객체 저장소 정상 응답을 확인했다.

### 공통 출시 노트

Tuti 1.7.0에서는 사진을 남기고 함께한 순간을 한 권으로 모으는 흐름을 더 가볍게 다듬었어요.

• 사진을 고르면 맞추기 없이 바로 남길 수 있고, 이야기는 원할 때 덧붙일 수 있어요.
• 마디를 목록으로 보거나 아직 담지 않은 마디를 찾아 하루마디에 담을 수 있어요.
• 책에서 마디를 수정한 뒤 읽던 곳으로 돌아오고, 장소 상세에서 바로 마디를 시작할 수 있어요.
• 하루마디 이름 예시와 선택 기간을 추가하고 초대에도 책의 맥락을 담았어요. 기간이 지나도 계속 채울 수 있어요.
• 함께 모은 마디를 PDF로 남기는 동선과 보관·내보내기 안내를 다듬었어요.

### iOS 프로모션 텍스트

사진만 남겨도 괜찮아요. 여행과 일상의 순간을 하루마디에 모아보세요. 함께 채울 기간은 자유롭게 정하고, 모인 마디는 책처럼 펼쳐 보거나 PDF로 간직할 수 있어요.

프로모션·출시 문구는 App Store Connect에서 별도 입력한다. 실물 주문·결제가 가능하다고 홍보하지 않는다.
