# Tuti 스토어 출시 노트

Android의 `출시 노트`와 iOS의 `이 버전에서 업그레이드된 사항`은 같은 원문을
사용한다. 플랫폼마다 실제 제공 기능이 다르거나 한쪽에만 적용되는 긴급 수정이
있는 경우에만 문구를 분리하고, 그 사유를 해당 버전 아래에 함께 기록한다.

## 1.0.0

- 버전명: `1.0.0`
- Android 출시명: `Tuti 1.0.0 — 오늘, 가볍게 떠나기`

### 공통 출시 노트

아래 원문을 Android의 `출시 노트`와 iOS의 `이 버전에서 업그레이드된 사항`에
동일하게 입력한다.

> Tuti 1.0.0에서는 기록을 간편하게 나눌 수 있도록 공유 기능을 개선했어요.

> • 남긴 기록을 웹 링크로 공개하고 공유할 수 있어요.
> • 링크를 받은 사람은 로그인 없이 기록을 볼 수 있어요.
> • 공개한 기록은 언제든 다시 비공개로 전환할 수 있어요.
> • 지난 기록을 기록집으로 묶어 미리보고 PDF로 간직할 수 있어요.
> • 화면 가독성과 서비스 안정성을 함께 개선했어요.
