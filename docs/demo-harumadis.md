# 시연용 하루마디 5권

2026-11-14 운영자의 요청 범위는 운영의 표시 이름 `정연한`·카카오 로그인 계정에
기존 데이터를 유지하며 비공개 하루마디 5권과 마디 15개(사진 11개·글 전용 4개)를 추가하는 것이다.
이 문서는 **실제 적용 완료 기록이 아니다**. 관리자 실행 결과를 확인해야 한다.

준비 검증: 사진 11개(변환 후 합계 1,672,656바이트)의 원본 SHA-256·해독 확인,
단위 테스트 10개, 격리 PostgreSQL 11의 실제 계정 구분·DB 오류 롤백·기존 원본
보존·5권/15마디 추가·재실행 무중복 시험을 통과했다. 운영 DB 쓰기·저장소 업로드와는 별개다.

- 산책은 천천히: 서울숲·선유도공원·글 전용 마디
- 물가에 두고 온 하루: 양화한강공원·여의도공원·글 전용 마디
- 골목이 들려준 이야기: 서촌·경의선숲길·덕수궁
- 조금 멀리 간 주말: 광교호수공원·한밭수목원·글 전용 마디
- 다시 펼쳐볼 풍경: 북서울꿈의숲·낙산공원·글 전용 마디

실제 개인의 방문·관계·건강 등은 추정하지 않은 가상 예시다. 뒷표지에 시연용임을
표시하며 네 가지 표지 유형을 섞고, 기억 기간과 마디 순서를 명시한다. 함께 채우기·
공개·PDF 생성·추천 및 작성 성공 이벤트는 만들지 않는다. 단, 보유량과 해당 계정의
장소 기반 추천에는 새 마디가 반영될 수 있다.

사진은 기존 공공 장소 DB의 공공누리 Type1만 선택하고 시각 확인한 원본의 URL·
SHA-256을 고정했다. 워터마크를 제거하지 않으며 사진 마디마다 제공자·이용조건·
출처 링크를 남긴다. [공공누리 제1유형 안내](https://www.kogl.or.kr/info/license.do)에
따라 출처를 유지한다. 개인 사진이나 다른 계정의 사진·본문은 읽거나 복사하지 않는다.

## 실행

NAS의 저장소 디렉터리에서 먼저 조회한다. 비밀번호를 저장하거나 실제 env 원문을
출력하지 않으며 기존 운영 ops 이미지를 사용한다. 로컬 빌드·앱 재시작·배포는 하지 않는다.

```sh
sudo sh scripts/ops/tuti-demo-harumadis --check
```

카카오·표시 이름에 맞는 계정이 하나여야 한다. 결과의 `targetUserId`, 기존 개수와
계획된 5권·15마디·11사진을 확인하고 출력된 `planHash`와 함께 적용한다.

```sh
sudo sh scripts/ops/tuti-demo-harumadis --apply --user-id TARGET_USER_ID --expected-plan-hash PLAN_HASH
sudo sh scripts/ops/tuti-demo-harumadis --verify --user-id TARGET_USER_ID
```

소스 3개가 커밋 원문인지 확인한 뒤 읽기 전용 사본만 컨테이너에 전달한다.
배포·백업 유지보수 잠금과 복원/원장 전환 보류를 존중한다. 조회는 사용자 ID·권한·
표시 이름·개수 및 공개 장소만 사용하며 이메일·인증정보·기존 기록 원문은 출력하지 않는다.

적용 시 사진의 유형·원본 바이트·해독을 확인하고 계정 소유의 새 저장소 키로 복사한다.
업로드 전에 30분 뒤 실행 가능한 정리 예약을 영속화해 중단 시 고아 객체를 회수한다.
정리 예약이 만료·인수되면 연결을 거절한다. 사용자 행 잠금 아래 5권·15마디·연결·
운영 작업 영수증과 정리 예약 취소를 한 트랜잭션으로 저장한다. 기존 파기 예약이나
사용자 행은 삭제하지 않는다. 실패 정리는 현재 DB가 참조하는 사진을 보존한다.

고정된 시연 배치 ID로 재실행을 구분한다. 이미 적용됐으면 중복 생성하지 않고,
일부가 삭제·변경된 상태면 자동 복원하거나 덮어쓰지 않고 중단한다. 확인 결과에는
개수와 검증 여부만 출력하며 사진 키·원문·인증자료는 출력하지 않는다.
