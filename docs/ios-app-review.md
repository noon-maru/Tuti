## 메타데이터

- 앱 이름 표기는 `Tuti`로 통일한다.
- 기존 부제 `Tunnel Tide over`는 현재 서비스 설명에 맞는 한국어 부제로 교체한다.
- 지원 URL은 `https://tuti.today/inquiry`를 사용한다.
- 스크린샷에는 비활성화한 소셜 로그인과 인터넷 공개 메뉴가 보이지 않아야 한다.
- 첫 판매 지역은 대한민국만 선택한다.
- 공개 UGC가 없는 현재 빌드 기준으로 연령 등급 질문에 답한다.
- 콘텐츠 권리는 한국관광공사 등 원천 데이터의 이용 조건과 보유 증빙을 기준으로 답한다.

## 업로드 전

1. 실제 기기에서 익명 데이터 삭제와 이메일 계정 삭제를 각각 확인한다.
2. 삭제 전 만든 기록·이미지와 과거 공개 주소가 더 이상 열리지 않는지 확인한다.
3. 위치 권한 허용·거부·지역 직접 선택 경로를 확인한다.
4. 실제 기기와 iPad 호환 모드에서 사진 촬영·사진 보관함 선택 및 권한 거부 경로를 확인한다.
5. 심사용 이메일과 고정 6자리 코드로 로그인한 뒤 계정 삭제까지 확인한다.
6. 관리자 감사 로그에서 이메일·코드·IP 원문 없이 요청·검증 결과가 남는지 확인한다.
7. Archive의 버전이 `0.4.0 (7)`, 대상이 iPhone 전용인지 확인한다.
8. Validate App, Upload, TestFlight 설치 테스트를 마친 뒤 build 7을 심사 버전에 연결한다.
