# 승인 대상 계정 정리 도구

상태: 제한적 운영 도구 설명. 2026-10-23 테스트 이용 종료 때의 일괄 정리는 완료됐다.
이 문서가 현재 사용자 삭제나 약관 즉시 시행을 새로 승인하지 않는다.
과거 고정 계정 수·컷오프·해시를 명령에 재사용하지 않는다.

## 조회 후 별도 승인

`scripts/ops/tuti-empty-account-cleanup`은 기본 조회 모드다.
관리자가 정한 `--created-before`와 `--expected-count`로 후보를 확인한다.
처음에는 `--apply`·`--include-records`를 붙이지 않는다.
관리자와 기준 이후 계정은 제외하고 기록·하루마디 없는 계정만 대상으로 한다.

출력의 후보 수·대상·`planHash`를 대조한 뒤 승인된 동일 계획에만
`--plan-hash`와 `--apply`를 추가한다. 수나 해시가 다르면 삭제하지 않는다.
기록까지 삭제하려면 별도 승인 후 `--include-records`로 새 계획을 조회·확정해야 한다.

## 보호와 실패 대응

- 배포·백업 유지보수 잠금과 미해결 원장·복원 대기를 확인한다.
- 커밋한 정리 코드의 해시를 검사하고 읽기 전용 마운트로 실행한다. 저장소 ACL을 넓히지 않는다.
- 사용자·소유 자료를 잠근 뒤 권한·생성 시점·자료 변경을 다시 검사한다. 중간에 달라지면 건너뛴다.
- 기존 계정 삭제 경로로 이미지·PDF·인증·위치 자료를 정리하고 삭제 원장 의무를 남긴다.
- 실패하면 후속 대상을 멈춘다. 일부 파일이 이미 지워졌을 수 있으므로 원장·DB·스토리지를
  확인하기 전 반복 적용하거나 백업으로 자동 되돌리지 않는다.
- 이메일이 같다는 이유로 다른 계정의 문의·인증 자료까지 삭제 범위를 넓히지 않는다.
- 백업과 분리 보존 자료의 파기·복원 통제는 [복원 방지 운영](./privacy-replay-operations.md)을 따른다.

이 도구는 운영 이미지·약관 플래그·공고·동의를 바꾸지 않으며 일반 계정 0개를
새로 만들기 위한 상시 자동 삭제 작업이 아니다.
