# 국외 처리·처리 근거 문안 결정

결정번호: LEGAL-TEXT-DECISION-20261022.
권한 근거: 운영자가 확보 답신·타사 사례에 기초한 문안 및 처리 근거 판단을 위임하고,
추가 전문가 자문은 후속으로 진행하도록 지시했다. 같은 대화에서 새 앱 출시 후
서버 전환을 유지하고 이번 범위를 문안 확정·공고 준비로 한정했다.
문서 검토 방식: 제공 자료·공식 문서·법령 및 실제 소스를 대조한 AI 보조 검토.
변호사 의견서·감독기관의 적법성 확인·실기기 시험 결과는 아니다.

## 1 국외 처리의 결정

요청한 웹/API 연결과 인증·문의 답변 알림 제공에 필요한 처리위탁·보관은 개인정보
보호법 제28조의8제1항제3호가목의 계약 체결·이행에 필요한 처리위탁·보관과
처리방침 공개를 근거로 작성한다. 선택 푸시는 사용자가 등록·수신을 요청한 범위이며
서비스 전체 이용에 필수로 만들지 않는다. 광고·기록 원문 AI 분석·독자적 제3자 제공을
이 근거에 끼워 넣지 않는다. 제공자 자체 운영자료의 처리 근거와 회사의 근거도 구분한다.

국가 표시는 미국 소재 수령자와 제공자의 글로벌 처리시설 범위를 병기한다.
Google/Firebase는 FCM이 글로벌 서비스임을 공식 안내하고 지원팀도 시설 소재 국가에서
처리될 수 있다고 답했다. 미국 전용이나 Tuti가 확정한 모든 국가의 목록으로 표시하지 않는다.
Apple·Cloudflare도 확보한 공식 글로벌 처리 안내를 기준으로 같은 한계를 표시한다.
개별 패킷의 모든 경유국을 새로 입증하는 과제를 문서 작성의 반복 선결조건으로 두지 않는다.

| 제공자 | 문안에 반영한 기간 | 가져오지 않은 추정 |
| --- | --- | --- |
| Firebase | 설치 ID 삭제 API 전까지, 호출 후 운영·백업 최대 180일. 메시지 전달·TTL 종료 시 폐기, 기본 미전달 최대 28일. 로그는 제한된 기간·통상 수 주라는 지원 설명 | 타사 표의 14개월·30일을 FCM 전체에 적용하지 않음 |
| APNs | 유효한 등록·전달 목적과 제공자 삭제 절차. 미전달 메시지 최대 30일은 해당 메시지에 한정 | 모든 토큰·로그 30일 삭제나 해제 즉시 전 세계 완전 삭제를 약속하지 않음 |
| Cloudflare | 전달·보안 목적에 필요한 기간과 적용 계약·처리약정의 삭제·반환 절차, 자체 운영자료는 제공자 조건으로 구분 | 다른 서비스의 Cloudflare DB·호스팅·분석 7일/6개월 설정을 Tuti Tunnel에 적용하지 않음 |

표시한 글로벌 범위와 목적·절차형 보관 기준의 고지 적정성에는 해석상 잔여 위험이 있다.
운영자의 지시에 따라 이를 밝힌 문안으로 확정하고 후속 전문가 자문 대상으로 기록한다.
타사도 같은 표현을 썼다는 이유로 적법성이 증명되었다고 판정하지 않는다.
새로운 확정 자료나 자문으로 정정이 필요해지면 고지·동의 필요성까지 재검토한다.

준비 검사에서도 `US`를 전체 국가 목록으로 가장하지 않는다. 글로벌 범위 설명·
제공자 공식 HTTPS 자료·판단 근거 번호를 함께 갖춘 고지 표현을 구분해서 검증한다.
이 형식 검사가 실제 모든 국가의 관측이나 적법성 보증은 아니다. 실제 공고와
네이티브 동작 확인 근거는 여전히 별도로 요구한다.

## 2 처리 근거와 이익형량

계정·기록 보관·기록집 제작·추천·문의는 이용자가 요청한 기능에 필요한 범위에서
제15조제1항제4호를 적용한다. 민감정보와 위치는 별도 동의를 유지한다.
아래 분석·보안·감사는 제15조제1항제6호의 엄격한 정당한 이익 요건을 기준으로 판단한다.
단순한 사업상 유용성이 아니라 목적과 상당한 관련이 있고 합리적인 범위여야 하며,
이용자 권리보다 회사의 이익이 명백히 우선하는 범위에 한정한다.

### 이용 단계 분석

- 목적: 추천·기록 등 핵심 기능에 도달하지 못하는 구간과 오류·재방문을 파악하여
  기능을 유지·개선. 이용자의 사생활·정치·건강·연애 상태를 추론하는 것이 아님.
- 필요성: 계정·활동 세션의 연결이 전혀 없으면 같은 동작의 중복, 단계별 이탈과
  재방문을 구분할 수 없다. 원문·정밀 위치·소셜 프로필 없이 지정 이벤트만으로 제한한다.
- 실제 코드: product-activity POST는 지정 action·UUID 세션·플랫폼·짧은 버전만 정규화하고
  추가 자유 입력을 저장하지 않는다. 계정·세션·action 중복을 upsert로 한정하고
  생성 때 180일 정리 기한을 지정한다. 정리 경로는 auth/retention에 있다.
- 대안 비교: 장기 원문·경로·IP를 분석 시스템에 복제하거나 외부 광고 SDK로 보내는
  방식은 필요하지 않아 채택하지 않는다. 180일은 반년 내 재방문·장애 추세 확인에
  한정하고 원본을 무기한 분석 자료로 유지하지 않는다.
- 위험: 임의 계정이라도 세션·행동을 묶으면 개인정보이며 기록 생성 여부 등은 사생활
  단서가 될 수 있다. 최소 이벤트·관리자 접근 통제·기한 정리·처리정지 창구로 제한한다.
- 판단: 광고·외부 AI·원문 추론·개인에게 불리한 자동 결정 없이 위 최소 범위를
  유지하는 현재 목적에 한하여 정당한 이익 근거를 문안에 채택한다.
  정지·삭제 요청을 접수하면 별도 동의 강요 없이 법 제37조의 요건에 따라 판단·안내한다.
  현재 셀프서비스 분석 토글이나 관리자 통계 제외가 원본 수집을 자동 중단한다고 약속하지 않는다.

### 보안·오류·관리자 감사

- 목적: 공격·비인가 열람·관리자 오남용을 확인하고 이용자 기록과 서비스 연속성을 보호.
- 필요성: 요청·대상·관리자·시점·결과의 최소 연결 없이 사건 조사와 권한 오남용 검증이
  어렵다. 이용자·관리자 동의 철회만으로 감사 흔적을 임의 삭제하는 것은 보호 목적과 충돌한다.
- 최소화: 원본 IP·전체 User-Agent 대신 HMAC·마스킹·요약 유형을 회사 DB에 저장한다.
  전용 오류 진단에는 원문·사진·정밀 좌표·토큰을 넣지 않는다. 관리자 조회에는
  목적·처리 번호·대상·시각을 남기고 접근을 제한한다.
- 기간: 일반 관측 90일, 전용 오류 1년, 기록 조회 감사 2년. 위치시스템 보안 기록은
  분류별 1년/5년이며 이용·제공사실 자료의 철회 파기를 우회하지 않는다.
- 판단: 보안·감사 이익은 사생활 탐색과 분리되고 이용자에게도 직접적인 보호 이익이
  있어 위 최소 범위에서 정당한 이익을 채택한다. 별도 안전조치 의무가 적용되는
  부분은 해당 의무를 병기하되 모든 진단을 법정 의무 자료로 일괄 표시하지 않는다.

### 신고·사건별 보전

요청 처리의 계약상 조치, 저작권·권리 침해 관련 법정 의무, 구체적 청구 방어에
필요한 정당한 이익을 구분한다. 자동 10년·무기한 보전 대신 사건·근거·대상·
책임자·종료 조건과 90일 재검토를 기록한다. 위치 철회처럼 특별한 파기 규정은
일반 분쟁 대비보다 우선 적용한다. 법정 의무 없는 전체 원문 보전을 허용하지 않는다.

## 3 타사 사례에서 채택한 것과 제외한 것

확인일: 2026-10-22. 타사 사이트에 게시된 자사 방침을 직접 확인했다.
타사의 실제 운영·적법성을 감사한 것은 아니다.

- [APEMO](https://apemo.im/privacy/): 처리 근거를 항목별로 나누고, Cloudflare·로그인·푸시의
  글로벌 시설 범위와 거부 효과를 표로 안내하는 구성을 참고했다. 분석·광고 서비스·
  이용 연령·개별 보관 설정은 Tuti와 달라 가져오지 않았다.
- [Factbox](https://fact-box.com/privacy): 근거·항목·목적·기간·거부 방법을 같은 표에서
  확인하는 구성을 참고했다. Cloudflare 호스팅·DB 국가·AI 업체·광고 처리는 복사하지 않았다.
- [ipTIME ID](https://iptime.com/iptime/etc/efm_iptime_id_policy.php): 푸시 발송 시점·최소 정보·
  알림 미사용에 따른 거부 효과를 구분한 안내를 참고했다. 토큰 기간이나 카메라 연동은
  Tuti에 적용하지 않았다.
- [Firebase 공식 안내](https://firebase.google.com/support/privacy)와 운영자가 제공한 Lawrence
  답신을 FCM 장소·기간의 사실 근거로 우선했다. 타사의 ‘미국’ 단독 표기가 이 답신과
  다르면 더 넓은 글로벌 범위를 표시했다.
- [개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611),
  [제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1034292763),
  [Google 방침](https://policies.google.com/privacy?hl=ko),
  [Apple 방침](https://www.apple.com/legal/privacy/en-ww/),
  [Cloudflare 방침](https://www.cloudflare.com/privacypolicy/)을 함께 대조했다.

## 4 이번 완료 범위와 후속

완료: 위 근거·이익형량·제공자 설명의 한계를 반영한 문안 확정 및 공고 준비.
보류: 실제 공고 등록·시행·구버전 제한·계정 삭제·운영 플래그 변경·앱 출시.
추가 법률자문: 문안 확정의 반복 대기 조건으로 두지 않고 후속 검토로 관리한다.
국가 범위·목적형 기간·계약 필요성과 정당한 이익 판단은 우선 자문 항목이다.
시행 단계에서는 앱·운영 이행을 사실대로 확인하며 이 기록을 시험 결과로 대신하지 않는다.
