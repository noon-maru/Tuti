## 확정한 공통 기준

- Tuti는 라이프로그 서비스이며 현재 무료 디지털 기록집을 제공한다. 실물 제작·
  결제·배송을 이미 제공하거나 유료 계약이 성립하는 것처럼 표시하지 않는다.
- 일반약관·개인정보 처리방침 안내·위치 동의·민감정보 별도 선택 동의·웹 공개·
  필요한 국외 이전 동의를 구분한다. 설치·업데이트·로그인·공고 열람은 동의가 아니다.
- 계정·기록은 유효한 보관 요청 동안, 분석 이벤트 180일, 일반 보안 관측 90일,
  문의 완료·최종 수정 중 늦은 때부터 3년, 관리자 기록 조회 감사 2년,
  일반 오류 1년, 미완료 PNG·푸시 전달 이력·전체/핵심 백업은 각각 30일을 기준으로 한다.
  삭제·철회·목적 종료가 먼저면 그 범위의 파기를 우선하며 사건별 보전은 최소화한다.
- 민감정보 기록의 비공개 보관은 서버 보호 기능과 기록별 선택 동의가 준비된 경우에
  한한다. 기존 표시 기록을 일반 기록으로 직접 바꾸지 않으며 철회·삭제 후 새 일반
  기록을 작성한다. 공개 제한은 완전 자동 탐지를 뜻하지 않는다.
- 회사 귀책·강행법규상 책임, 적법한 권리 행사·법정 입증책임을 포괄 배제하지 않는다.
- 공고일·시행일·버전은 실제 승인·등록할 공고의 메타데이터로 확정한다. 오늘을
  시행일로 임의 기재하거나 미공고 상태에서 30일이 경과했다고 계산하지 않는다.

## 국외 처리·처리 근거의 결정과 후속 자문

Firebase의 글로벌 처리·설치 ID 삭제와 메시지 TTL·기술 로그의 구분은 제공받은
답신과 공식 자료로 반영했다. Apple의 답신을 추가로 기다리는 것을 일반약관 공고의
필수 조건으로 두지 않는다. 그러나 확보한 설명이 법정 국가·보유기간 고지와
적용 근거를 충족하는지는 다른 문제다. Cloudflare는 선택 푸시와 달리 기본 웹/API
경로 전체를 중계하므로, 푸시를 끄는 것만으로 이 쟁점이 없어지지 않는다.

운영자의 후속 지시로 글로벌 처리 범위·제공자별 목적/삭제 절차를 명시하고,
제28조의8제1항제3호가목의 계약 이행 위탁·보관과 방침 공개를 근거로 문안을 확정했다.
이용 분석·보안·감사의 목적·필요성·대안·권리 영향은 processing-decision.md에 기록했다.
새로운 개별 국가 목록·APNs 고정 보관 상한을 입증했다고 표시하지 않고 해석상 잔여
위험을 후속 자문에 남긴다. 문안 승인을 위해 추가 답신·전문가 자문을 반복 대기하지 않는다.
현재 처리의 법적 의무가 새 방침 시행까지 유예되거나 타사 사례가 적법성 보증이라는 뜻은 아니다.

## 문안과 운영 이행의 구분

처리 항목·목적·기한을 기재한 것과 처리 근거의 적정성 검토는 다르다. 요청한 계정·
저장 기능의 계약 이행과 달리 이용 단계 분석, 보안·관리자 감사, 사건별 보전에는
processing-decision.md의 필요성·최소성·이익형량 판단을 적용한다.
현재 180일 이벤트 경로는 계정·세션·행동·플랫폼·앱 버전만 지정 항목으로 저장하고
기록 원문·정밀 좌표를 이벤트 본문으로 받지 않지만, 그 최소화만으로 법적 근거가
자동 확정되지는 않는다. 이번 문안은 별도 판단 기록을 근거로 확정하며
일반약관 필수 동의가 포괄적으로 해결한 것으로 표시하지 않는다.

실기기·기존 설치 업그레이드의 SDK 동작, 민감정보·확장 보유기간 정리의 운영 활성화,
현재 공개 연락처의 새 팩스 반영은 별도 검증·배포 항목이다. 성공한 전체·핵심 백업
격리 복원과 메일 첨부 전달 시험을 다시 미완료로 돌리지 않는다. 이번 원문 수정도
실제 사건 통지·원장 재반영·법정대리인 관계의 실증을 대신하지 않는다.

`review-manifest.json`은 각 파일의 무결성·검토 상태를 기록한다. 해시는 파일 식별용이며
공고 DB의 구조화 원문 해시나 승인번호가 아니다. 승인 원문 변경은 별도 개정 절차를 거치고 검사를
통과시켜야 한다. 명세의 publicationApplied·enforcementApplied=false는 확정 당시 문서 작업의 범위이며 현재 운영 미시행을 뜻하지 않는다.
운영 실기기·예약 작업·삭제 원장 등의 실제 확인 근거를 문안 승인으로 대체하지 않는다.

## 공고 묶음 준비

`pnpm legal:notice:prepare`는 네 원문과 해시·판단 위임 근거를 검증하고 공고용 구조화
원문·문서별 승인 확인 파일을 stdout에 출력한다. 기본 실행은 일정 없는 준비 묶음이다.
`--effective-at=ISO시각`을 주면 그 실행 시각부터 30일 이상의 변경 공고 계획도 검증한다.
어떤 모드도 파일·DB·환경변수·계정·동의 기록을 변경하지 않는다.
실제 공고 시에는 새로 준비·확인한 문서별 입력을 기존 announce 도구에 전달하며,
공고 뒤에도 일반약관 강제와 다른 정책의 시행본 교체는 앱 출시 후 별도 전환한다.
