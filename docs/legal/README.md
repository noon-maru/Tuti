# 약관·개인정보 운영 안내

정리 기준: 2026-10-29. 이 문서는 현행 코드·확인된 전환 이력의 입구다.
약관 전문·법률자문·실시간 운영 점검을 대신하지 않는다.

## 현행 원문과 시행 이력

원문 버전은 **2026-10-22**다. 버전의 날짜와 실제 공고·시행 시각은 다르다.

| 구분 | 확인된 전환 기록 |
| --- | --- |
| 일반약관 최초 등록 | 2026-10-23 14:11:40 KST |
| 개인정보·위치약관·공개 운영정책 공고 | 2026-10-23 15:31:02 KST |
| 개별 정책 시행 메타데이터 | 2026-10-23 15:35:43 KST |
| 서버 강제 전환 확인 | 2026-10-23, 현행 일반약관 영수증 요구·구규약 요청 차단 확인 |

위 내용은 당시 관측이며 지금 실행 중인 플래그·계정별 동의 상태를 자동 보증하지 않는다.
최초 적용은 승인된 테스트 이용 종료와 계정 정리 후의 신규 계약 경로로 진행했다.
완료된 공고·초기화 명령을 다시 실행하거나 새 계정을 삭제해 조건을 맞추지 않는다.

- 공개 문서: `/legal/service-terms`, `/legal/privacy`, `/legal/location-terms`,
  `/legal/community-guidelines`, `/legal/notices`.
- [확정 원문 묶음](./release/README.md): 원문·판단 기록·해시 명세.
- 런타임 묶음: `src/shared/legal/finalizedDocuments.json`.
- 운영 시행·공고·개별 동의의 실제 근거: DB의 릴리스·공고·계정별 영수증과 서버 설정.

문서 정리로 승인 원문·구조화 해시·공고 이력을 덮어쓰지 않는다. 원문을 변경해야 하면
새 개정·승인·공고 절차를 거친다. 원문의 옛 제품명과 현재 마디·하루마디 명칭은
일반 UI 문구 치환과 별개다.

## 앱 진입과 선택 동의

최초·미동의 사용자는 `/entry`에서 필수 연령 확인·일반약관에 명시적으로 동의한다.
위치 동의는 별도 선택이고, 기기 권한·좌표 요청은 작은 여행에서 필요한 시점에만 진행한다.
로그인이나 앱 업데이트만으로 동의 영수증을 만들지 않는다.

동의 완료 사실의 계정별 로컬 캐시는 화면 대기를 줄이는 용도다. 서버 검증과 미동의
차단을 대체하지 않는다. [시작·약관 캐시](../startup-performance.md)에서 구현을 설명한다.
민감정보는 현재 작성 UI에서 받지 않는다. 서버의 기존 보호·철회 경로가 있다는 이유로
해당 기능이 사용자에게 제공된다고 안내하지 않는다.

읽기 전용 운영 상태 조회는 `sudo /usr/local/sbin/tuti-legal-operations-inspect`를 사용한다.
`operationalCompletionVerified`나 예약·전달 확인 항목은 실제 근거 없이는 true로 바꾸지 않는다.
조회 성공·예약 성공·실제 사건 처리·실기기 검증은 각각 별개다.

## 외부 처리와 후속 검토

- Kakao 좌표 처리는 운영자 판단에 따라 처리위탁(`processor`)으로 안내한다.
  이를 별도 서면 확인이나 신규 계약 체결이 있었다는 뜻으로 확대하지 않는다.
- Firebase는 확보한 지원 답신에 따라 글로벌 처리, 설치 ID·메시지 TTL·기술 로그를 구분한다.
  Tuti 자체 30일 정리와 제공자 전체 삭제 기간은 같지 않다.
- Apple 개인정보팀 회신은 App Store 다운로드·인앱결제 등의 독립 처리자 역할을 설명했지만
  **APNs의 처리 관계는 확정하지 않았다**. APNs는 개발자 지원에 서비스·토큰·일반 알림
  페이로드를 명시해 추가 확인할 대상이다. 확인 전 임의 국가·고정 보관 상한을 만들지 않는다.
- 원문의 처리 근거 판단과 남은 해석상 위험은 `release/processing-decision.md`에 보존한다.
  이 안내를 적법성 보증이나 외부 전문가 승인으로 인용하지 않는다.
- 마디의 혼잡도·테마·난이도 입력 제거 등 이후 기능 축소는 원문 개정 검토 때 대조한다.
  현재 수집하지 않는 과거 필드를 문서만 보고 다시 수집하지 않는다.

## 초안·과거 자료

남아 있는 `*-draft.md` 세 문서는 확정 전 편집·검증 입력이다. 일반약관·개인정보·위치 초안은
준비 도구와 회귀 시험에서도 사용하므로 그대로 보존한다. 중복된 공개 운영정책 초안은 제거하고
확정본으로 통합했다. **초안은 현행 공개 원문이 아니며**
초안의 미완료 목록이나 과거 ‘시행 전’ 설명을 현재 운영 절차로 쓰지 않는다.

긴 전환 일지는 [과거 검토 기록](../archive/legal-transition-2026-10.md), 1.4 앱의
일회성 변경은 [앱 전환 이력](../archive/app-transition.md)으로 분리했다.
개발 DB의 운영 약관 복사는 공개 원문·공고 메타데이터를 대상으로 하며 운영 계정·동의·세션은
복사하지 않는다. `scripts/ops/tuti-dev-legal-setup`은 **개발 일반 계정 정리와 개발 앱 재생성도
수행하는 도구**이지 단순 조회가 아니다. 개발 자료 삭제 승인·개발/운영 DB 및 객체 분리·
운영 정책 메타데이터 일치 확인 후에만 실행한다. 조회 실패를 임의 동의나 운영 DB 연결로 우회하지 않는다.
