# Tuti 사업자 보호와 장기 보유 설계

작성 기준: 2026-10-19의 검토 근거. 아래 시행 전 목록·제안은 당시 판단이다.
현행 원문·실제 시행은 [법적 문서 안내](README.md)를 따르며 이 문서는 현재 준비 상태나
특정 조항의 유효성을 보장하는 법률의견서가 아니다.

계정·기록 보관이라는 계약 목적이 실제 계속되는 동안은 필요한 정보를 유지하고,
목적이 끝난 개인정보는 파기하되 적법한 법정 기록과 사건별 증거를 분리한다.
장기 사업 분석에는 진정한 익명 집계를 사용한다. 면책은 서비스가 약속하지 않은
범위, 회사에 귀책 없는 원인, 손해·인과관계·예견 가능성과 법정 책임감면을 구체화한다.

## 보유 확대의 경계

| 분류 | 사업자에게 확보하는 범위 | 넘지 않는 경계 |
| --- | --- | --- |
| 계정과 보관 요청이 유효한 기록·PDF | 서비스 제공에 필요한 계정 존속 기간 동안 장기 유지, 단기 일률 만료 약속을 두지 않음 | 목적 종료·삭제·철회에도 모든 원본을 계속 남기는 권한은 아님 |
| 완료 문의·신고의 최소 증거 | 처리 후 3년 이내를 목표 상한으로 검토하고 해당 사건에 필요한 기간만 채택 | 무료 문의에 일률적 법정 3년 의무가 있다고 주장하지 않음. 근거·이익형량을 입증하지 못하면 먼저 파기 |
| 실제 분쟁·공격·법적 요청 | 사건과 필요한 권리 행사·의무 이행이 끝날 때까지 적법한 대상만 선택 보전, 90일마다 필요성 검토 | 소멸시효 5년·10년을 모든 개인정보의 보유 근거로 사용하지 않음 |
| 최소 차단 식별값 | 실제 차단이 필요한 기간 유지하고 주기적으로 재검토 | 정상 이용자 일반 로그를 차단 자료로 일괄 전환하지 않음 |
| 익명 통계 | 익명성 검증 후 고정 만료 없이 장기 사업·품질 분석에 활용 | UUID·해시·정밀 시간·장소를 남긴 가명자료는 익명이라고 부르지 않음 |
| 향후 실물 판매의 거래기록 | 해당 전자상거래 기록의 법정 5년·3년·6개월 보존 | 아직 없는 유료 거래를 근거로 무료 기록·사진 전체를 선제 보관하지 않음 |

표의 회사 제안값은 법적 최장기간이 아니다. 모든 개인정보를 최대 몇 년 보관해도
된다는 공통 수치는 없고, 실제 목적·수집 근거·필요성·철회와 다른 법률에 따라
가능한 기간이 달라진다. 별도 선택 동의를 받더라도 최소 처리와 철회권은 남는다.

기존 고객 전체에 새 기간을 소급하지 않는다. 기존 동의기간 연장이나 목적 변경은
해당 요건과 필요한 새 동의를 갖춘 자료에만 적용한다. 이번 문서 수정은 DB의
180일 이벤트·90일 관측자료 파기나 계정 삭제 코드를 변경하지 않는다.

## 사건별 증거 보전의 실행 조건

보전 대상은 구체적인 분쟁·공격·청구에 대응하는 데 필요한 최소 자료다.
원래 수집 목적과 근거, 목적 외 이용 제한과 합리적 추가 이용 요건,
처리정지·철회 제한의 별도 요건을 함께 심사한다. 아래 사항을 보전대장에 남긴다.

1. 사건 관리번호와 객관적인 보전 사유
2. 처리 근거, 자료 항목·범위와 다른 방법으로 대체하기 어려운 이유
3. 대상자·책임자·접근 권한과 원본 보관 위치
4. 시작일, 종료 조건, 다음 검토일과 실제 재검토 결과
5. 삭제·철회 요청의 처리 결과와 안내, 최종 해제·파기 기록

일반 자료와 분리하고 사건 대응 이외의 추천·마케팅·AI 처리에는 이용하지 않는다.
위치정보법의 철회 파기처럼 별도 법률이 강하게 제한하는 자료를 일반 보전
조항에 포함하지 않는다. 법원의 명령·법정 의무 등 실제 충돌이 있으면 개별 검토한다.

## 면책과 운영 재량의 확대

서비스 이용약관 제7·8·14·15·17·19조를 다음과 같이 구체화했다.

- 추천의 만족·방문·도착·안전과 사업적 수익을 보증하지 않는다.
- 표시하지 않은 영구 원본 보관·버전 복구·인쇄 결과·무료 서비스의 가용률과 복구시간을 약정하지 않는다.
- 법령·별도 약정이 없는 무상 기능 변경 자체의 정액 보상·서비스 크레딧을 약정하지 않는다.
- 기기·권한·인증·외부 API·이용자 선택으로 발생한 손해 중 회사 귀책 없는 부분을 구분한다.
- 통상손해와 예견 가능한 특별손해, 이용자의 기여 과실에 관한 법정 기준을 적용한다.
- 권리 침해로 회사가 실제 입은 법령상 인정 손해와 비용은 이용자의 귀책 범위에서 청구할 수 있다.
- 적법한 게시물 중단·재개·임시조치에 법정 책임 제한·감면을 적용받을 수 있게 절차를 구체화한다.
- 법적으로 허용되는 약관 변경에는 별도 명확한 고지와 상당한 기간을 전제로 제한적인 동의 의제를 둔다.

회사의 일반 과실까지 전부 면책하거나 모든 배상을 최근 결제액으로 제한하지 않는다.
법정 위자료·손해배상, 고의·중과실과 불공정한 위험 전가 제한을 배제하지 않는다.
사용자에게도 사본 보관과 정상적 주의를 요구하되 회사의 핵심 데이터 보호 의무를 넘기지 않는다.

## 시행 전에 남은 일

- 일반 약관 동의·중요 내용 표시·문서 스냅샷·버전·시각 보존 구현 후 운영·실기기 검증
- 새 보유 근거와 3년 목표 상한의 필요성 평가, 자료별 최종 기한 확정과 별도 저장·파기 구현
- 사건별 보전대장·권한·기한 검토와 해제 기능
- 진정한 익명 집계 생성·소수 집단 처리·재식별 위험 검증
- 관리자 접속기록 1년·2년 적용 대상 확인과 기존 위치 감사 기록과의 구분
- 위치 동의 철회 시 확인자료 파기 코드 구현 완료 후 운영 검증 및 기존·백업 자료 점검
- 게시물 법정 임시조치 통지·30일 기한, 저작권 중단·재개 수령인과 법정 절차
- 민감정보 공개 가능성·비공개 방법 안내와 필요한 처리 근거
- 위탁·국외 이전·백업 보관·복구 후 재삭제의 실제 조건 확정
- 공고·시행일 확정, 기존 이용자 경과조치와 법률 전문가 검토

위 구현과 검토 전에는 초안을 운영 약관으로 교체하거나 실제 보유기간을 연장하지 않는다.

## 법령별 판단 근거

계약 이행에 필요한 처리와 정당한 이익의 엄격한 요건은
[개인정보 보호법 제15조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033214947),
목적 달성·불필요 자료의 파기는
[제21조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900078981),
처리정지·철회와 예외는
[제37조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033216171)를 확인한다.
정당한 이익 하나로 목적 외 이용이나 모든 철회 거절이 허용되는 것은 아니다.

익명 집계와 가명정보는 각각
[제58조의2](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1034292489),
[제28조의2부터 제28조의5](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334887)를 구분한다.
향후 거래기록은 [전자상거래법 시행령 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=63460)의 적용 범위로 한정한다.

위치 철회 파기는 [위치정보법 제24조](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0024&lsiSeq=277359&urlMode=lsScJoRltInfoR)를 따른다.
관리자 접속기록은 일반 사용자 로그와 달리
[개인정보의 안전성 확보조치 기준 제8조](https://law.go.kr/admRulLsInfoP.do?admRulSeq=2100000281400)의 보존 대상·조건을 검토한다.

불공정 면책·급부 변경·의사표시 의제의 한계는
[약관규제법 제6조부터 제10조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1025032405),
[제12조·제14조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1025032407)를 기준으로 검토했다.
특별손해와 과실상계는
[민법 제393조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032403515),
[제396조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026989959)를 적용한다.

게시물 책임감면은 [정보통신망법 제44조의2](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025056627),
[저작권법 제103조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029423165)의 실제 이행 요건을 따른다.
