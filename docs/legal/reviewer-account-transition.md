# 심사용 계정·테스트 콘텐츠 전환 결과

상태: 2026-10-23 완료된 일회성 이전의 기록. 새 계정 생성·삭제·공고 절차가 아니다.
현재 로그인 설정·비밀번호는 환경변수와 스토어 심사 정보에서만 관리하며 이 문서에 기록하지 않는다.

## 수행한 범위

1. 기존 심사용 테스트 마디 3개·이미지 3개를 별도로 보관하고 해시·전체 이미지 해독·원본 일치를 확인했다.
2. 운영자가 승인한 기존 일반 계정을 삭제했다. 관리자 자료는 제외하고 기존 파기·원장 절차를 사용했다.
3. 최초 약관 등록·공고·서버 전환 후 새 심사용 계정을 생성하고 명시적 동의를 받았다.
4. 새 심사용 계정에 비공개 마디 3개를 새 ID·사진 객체로 등록했다.
   결과: records=3, imagesReadBack=3, privateOnly=true, consentsCopied=false.

인증수단·세션·동의 영수증·공개 링크는 이전하지 않았다. 운영자가 심사 정보의 로그인 값도
현재 계정과 맞춰 관리한다. 이 이전 결과가 앱 심사 통과나 실제 이용자 자료 이관의 일반 승인은 아니다.

## 도구·사본의 수명

이관 도구는 작업 후 제거했다. 남아 있는 `tuti-reviewer-records-archive`는 보관·검증용 코드이며
예전 계정·이미지를 다시 가져오는 명령이 아니다. 과거 export·삭제·공고 명령을 반복하지 않는다.
사용자가 이전 사본의 제거도 요청했으므로 이를 상시 복구용 자료로 안내하지 않는다.
이 문서 정리에서는 NAS의 잔존 사본 유무를 새로 조회하거나 파일을 삭제하지 않았다.
개별 사본 제거 확인과 30일 full/core 백업·삭제 원장 통제는 별개다.

현행 약관과 공고·시행 시각은 [법적 문서 안내](./README.md), 백업·파기는
[복원 방지 운영](./privacy-replay-operations.md)을 따른다. 실패·승인 검토의 당시 상세는
Git 이력에 남기고 현행 체크리스트에 재사용하지 않는다.
