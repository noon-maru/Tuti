# 제품 방향과 확장 경계

기준: 2026-11-20, Tuti 2.0.0. 고객·말투·시각 원칙의 원문은
[브랜드 정의서](./brand-definition.md)와 [설계 원칙](./target-and-design-principles.md)이다.
현재 제공 기능·배포 상태는 [2.0 제공 범위](./tuti-2-implementation.md)에서 관리한다.

## 기록이 중심, 나들이는 다음 시간을 돕는 기능

Tuti는 반려동물과 함께한 시간과 보호자 자신의 하루를 사진·이야기로 남겨 한 권에 모으는
라이프로그 서비스다. 반려묘와 집에서 보낸 시간이나 반려동물이 등장하지 않는 일상도 핵심 기록이다.
반려동물 등록·외출·연속 작성은 이용 조건이 아니다.

책장은 남긴 시간을 읽는 중심이다. 나들이는 반려견과 다음에 함께할 시간을 발견하도록 돕고,
선택한 장소·책의 맥락을 작성과 다시 읽기로 잇는다. 추천·출발·방문 자기보고·마디 저장은
각각 별개의 행동이며 한 단계가 다음 행동을 자동 생성하거나 방문을 인증하지 않는다.
실제 연결은 [행동 루프](./recommendation-action-loop.md)를 따른다.

## 무료 디지털 경험과 실물 가설

현재 마디·하루마디·함께 채우기·PDF 경험을 제공한다. 실물 소장 버튼은 준비 중 안내와 관심 신호이며
주문·정상가 결제·인쇄·배송·매출이 아니다. 디지털 기록을 불편하게 만들어 구매를 유도하지 않는다.

실물 하루마디는 후속 BM 검증 대상이다. 사용자 인터뷰의 관심, 버튼 선택, 가상 시나리오를
실제 구매 수요나 재구매 성과로 해석하지 않는다. 검증에 필요한 최소 단계와 보호 조건은
[실물 검증 계획](./harumadi-bm-validation-plan.md)에서만 관리한다.

## 후속 판단

- 현재 장소의 출처·조건·지역별 부족과 추천 만족을 먼저 관찰한다. 신규 장소 수집·큐레이션 확대는 별도 작업이다.
- 기존 기록의 소유권·복구 통제·기기 초안·계정 간 격리를 유지한다. ‘영구 보존’이나 복원 보장을 홍보하지 않는다.
- 핵심 성과는 자발적인 작성·다른 날짜의 재열람·실제 공동작성이다. 사용량·구매 관심·실제 매출을 합산하지 않는다.
- 주문·기관 서비스·공동 프로필 같은 확장은 문제·수요·권한·보관·운영 비용을 검토한 뒤 별도 범위로 결정한다.

1.x의 여성·커플 우선 모집, 2~3만 원 가격, 유료 PDF·데이터 판매 우선순위와 상세 제안 모델은
현행 실행 사양에서 제외했다. 결정의 맥락은 [이전 사업모델 요약](./archive/business-model-exploration.md),
이전 전문은 Git 이력에 남는다. 이 정리는 새로운 가격·상품·출시 일정을 확정하지 않는다.
