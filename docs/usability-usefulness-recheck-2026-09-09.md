**남은 우선 수정 사항**

**1. P1 — 미확인 시간 후보를 조건에 맞는 추천으로 안내한다.**

서울 시청의 60분 요청은 서울역사박물관·국토발전전시관·한국은행 화폐박물관·서울시립미술관 서소문본관·서울역 옥상정원을 반환했다. 모두 경로와 전체시간 판정이 없었다. 실제 UI에는 ‘선택한 조건에 맞는 5곳만 골랐어요’, ‘지금 위치에서 큰 이동 없이 닿을 수 있어요’가 표시됐다. 카드의 이동시간 확인 안내와 상단의 조건 충족 표현이 맞지 않는다.

`src/server/recommendations/executionEligibility.ts`는 `fitsAvailableTime !== false`만 검사하므로 미확인도 통과한다. 근처 장소를 탐색용으로 보여주는 것은 가능하지만, 시간 검증 결과와 구별해야 한다. 권장: 확인된 결과를 우선하고 미확인은 별도로 표시하며 조건 충족 문구를 바꾼다. 빈 결과에서는 시간 확대·출발점 변경으로 이어지는 과업을 제공한다.

**2. P1 — 무료 조건은 여전히 요금 데이터가 비어 있으면 유료 장소를 통과시킨다.**

세종 무료 요청에서 국립세종수목원이 포함됐다. 당시 DB의 요금은 비어 있었다. 같은 서비스의 상세 API를 조회하자 성인 5,000원과 면제 조건이 반환됐고, 이후 같은 무료 추천에서는 수목원이 빠졌다. 이는 서비스 데이터 간 불일치의 직접 재현이며 외부 가격의 별도 현장 검증은 아니다.

`src/server/recommendations/admissionFee.ts`는 무료 요청에서도 `unknown`을 허용한다. 권장: 무료 확정 후보와 요금 미확인 후보를 구분하고, 추천 전에 요금 정보를 보강한다. 기존 데이터의 일괄 보강도 필요하다. 상세 페이지를 누른 이력에 따라 무료 필터의 정확성이 달라지면 안 된다.

**3. P1 — 분위기 태그 수정이 기존 추천 데이터에 충분히 반영되지 않았다.**

‘탁 트인’ 조건에 서울의 상상톡톡 미술관·CTS아트홀, 대구의 향토역사관·대구콘서트하우스 등이 포함됐다. 기존 DB에 이 장소들의 `open` 태그가 남아 있었다. 동일 데이터에 새 `derivePlaceMoodTags`를 적용하면 해당 태그가 제거된다. 새 분류 로직과 실제 추천이 사용하는 저장값 사이에 차이가 있다.

권장: 새 태그 규칙으로 기존 데이터를 재계산하고 지역별 표본을 확인한다. 이번 점검에서는 일괄 데이터 갱신을 실행하지 않았다. 코드 수정만으로 이 문제가 해결됐다고 판단할 수 없다.

**4. P1 — 대구 출발 장거리 실패와 위치 미제공 오류를 구별해야 한다.**

같은 ‘내일 당일치기·조용함’ 조건에서 서울 시청 출발은 여정 5개를 약 22.4초에 반환했다. 대구 동성로 출발은 개발 API에서 약 6.9초 후 503, 격리 실행에서도 약 16.5초 후 같은 실패였다. 정확한 원인은 확정하지 못했다. 이 표본만으로 대구의 모든 장거리 이동이 실패한다고 일반화할 수는 없다.

좌표 없이 지역만 선택한 장거리 요청 4개도 모두 `long_distance_unavailable`이었다. `longDistanceAvailability.ts`는 출발 위치 부재와 여정 부재를 같은 오류로 처리하며, 사용자에게는 교통편 조회가 잠시 원활하지 않다는 취지로 안내한다. 위치가 필요한 상황에서는 재시도만으로 해결되지 않는다.

권장: 위치 필요·교통 조회 실패·조건에 맞는 여정 없음의 안내와 후속 행동을 분리한다. 대구 출발 경로의 후보·출발 허브·왕복편·연결 구간을 단계별로 기록해 실패 원인을 확인한다. 좌석 구매 가능 여부와 실제 운행 보장은 이번 테스트 범위 밖이다.
