# 위치정보 이용 흐름

기준: 2026-10-29. 위치는 작은 여행을 위한 선택 기능이다. 마디·하루마디만 이용할 수 있다.

## 요청 시점

- 첫 약관 화면의 위치 동의는 선택이며 필수 두 항목 자동 체크에 포함하지 않는다.
- 로그인 직후에는 홈 책장으로 이동하고 기기 위치를 요청하지 않는다.
- 작은 여행 `/explore` 첫 진입에서 위치가 필요할 때 서버의 현행 위치 동의를 확인한다.
  동의가 유효하면 기기 위치를 요청하고, 미동의면 먼저 위치 약관 바텀시트를 표시한다.
- 동의 후에도 OS 권한은 별도로 받는다. 거부·철회·권한 오류·시간 초과에는 직접 지역 선택으로 이어진다.
- 질문 없이 시작하는 경우도 위치 안내 순서를 생략해 마지막 추천 준비 화면으로 보내지 않는다.
- 마지막 진입은 위로 스와이프하는 동작이며 예전 `장소 확인하기` 버튼은 현재 기준이 아니다.
- 백그라운드 위치·지속 이동 경로 추적은 하지 않는다.

## 상태와 동의

법적 동의(`accepted/declined/withdrawn`)와 기기 권한
(`unknown/prompt/granted/denied/unavailable/timeout`)을 구분한다.
현재 좌표는 런타임 상태에만 두고 Preferences에 영속 저장하지 않는다.
서버 동의 이벤트에는 사용자·버전·연령 확인·플랫폼·시각을 남기되 원본 좌표는 넣지 않는다.

다른 기기의 철회·일시중지를 서버 확인에서 반영한다. 약관 버전·동의 유효성을
로컬 캐시만으로 통과시키지 않으며 기기 권한 허용을 법적 동의로 취급하지 않는다.
현행 원문 버전 `2026-10-22`와 실제 시행일은 [법적 문서 안내](./legal/README.md)를 따른다.
편집 버전 날짜를 시행일로 표시하지 않는다.

## 데이터 처리

- 추천·이동시간·출발 계획의 요청 처리에 좌표를 사용하지만 계정·마디에 현재 좌표를 저장하지 않는다.
- 메모리의 이동시간 query key에 좌표가 포함될 수 있으나 해당 키를 영속화하지 않는다.
- 장거리 출발 거점 경로는 약 100m 위치 구간 키로 최대 30분 서버 메모리 캐시를 사용한다.
- 관광지 좌표를 사용하는 공개 장소 캐시는 사용자 현재 위치와 구분한다.
- 사진 촬영 위치는 위치 동의한 경우에만 주변 장소 제안에 읽고, 업로드 이미지의 EXIF는 제거한다.
- 좌표를 받는 API는 서버에서 위치 동의를 확인한다. 추천 이력에는 정밀 거리 대신 거리 구간을 남긴다.
- 이용·외부 전달 확인자료에는 원본 좌표 없이 경로·시각·만료를 기록하고 기본 6개월 정리를 수행한다.
  철회 범위의 파기는 단순 만료 작업과 별도로 처리한다.

## 외부 좌표 처리

`LOCATION_EXTERNAL_COORDINATE_MODE`의 세 모드를 구분한다.

| 모드 | 동작 |
| --- | --- |
| `pending` | Kakao 계열로 현재 좌표 전달을 막음 |
| `processor` | 처리위탁 고지·운영 판단에 따른 경로 계산 허용 |
| `third_party` | 별도 제공 동의·통보 기능이 준비되지 않으면 차단 |

현행 운영 판단은 **처리위탁**이다. 이 판단과 별도 서면 회신·계약을 확보했다는 사실은
구분한다. 과거 ‘서면 확인 전 pending 유지’ 문구를 현재 설정 지침으로 쓰지 않는다.
구체적인 추가 확인 항목은 [이전 문의 기록](./archive/kakao-location-processing-inquiry.md)에 남긴다.
외부 처리 목적·수신자·글로벌 처리 고지는 현행 개인정보 처리방침을 따른다.

## 설정·권리·운영

위치 설정에서 일시중지·철회와 이용 내역 조회를 제공한다. 중지·철회 즉시 현재 좌표·위치 추천·
이동시간·출발 계획 캐시를 비운다. 서버 철회는 원장 의무와 삭제 작업을 통해 이행하고
실패 시 재시도한다. UI 초기화만으로 전체 파기가 입증됐다고 표시하지 않는다.

| 자료·작업 | 위치 |
| --- | --- |
| 동의 | `location_consent_events` |
| 이용·제공 확인자료 | `location_usage_logs` |
| 접근·권한·점검 감사 | `location_security_audit_events` |
| 보관기한 정리 | `/usr/local/sbin/tuti-location-compliance-purge` |
| 보호 점검 | `/usr/local/sbin/tuti-location-security-inspection` |
| 인프라 권한 변경 기록 | `/usr/local/sbin/tuti-location-access-change` |

운영 호출 권한·인자·예약은 [운영 명령](./operations.md)을 따른다. 관리자 화면에서도
원본 위경도는 제공하지 않는다. 웹·Mac의 시스템 위치 실패는 앱 재시도만으로 해결되지
않을 수 있으므로 오류를 구분하고 지역 선택을 제공한다.
