# 위치정보 이용 흐름

## 제품 원칙

- 앱을 실행하자마자 위치 권한을 요청하지 않는다.
- 최초 질문을 마치고 `장소 확인하기`를 누른 직후 Tuti의 위치 이용 안내를 먼저 보여준다.
- 이용자가 명시적으로 동의한 경우에만 기기의 위치 권한을 요청한다.
- 거부, 철회, 권한 오류가 발생해도 위치 없는 추천과 기록 기능은 계속 제공한다.
- 백그라운드 위치와 지속적인 이동 경로 추적은 사용하지 않는다.

## 상태 분리

법적 동의와 기기 권한은 서로 다른 상태로 관리한다.

- 법적 동의: `accepted`, `declined`, `withdrawn`
- 기기 권한: `unknown`, `prompt`, `granted`, `denied`, `unavailable`, `timeout`
- 현재 좌표: 런타임 Zustand 상태에만 유지하고 Preferences에는 저장하지 않는다.

동의 기록에는 약관 버전과 처리 시각만 저장한다. 약관 버전이 바뀌면 다음 위치 이용 시 다시 동의를 받는다.

## 화면 흐름

1. `장소 확인하기` 선택
2. 개인위치정보 이용 안내 바텀시트 표시
3. 만 14세 이상 및 위치기반서비스 이용약관 동의
4. 기기 위치 권한 요청
5. 허용 시 위치 기반 추천, 거부 시 위치 없는 추천
6. 메인 메뉴의 `위치 설정`에서 재동의 또는 철회

거부 상태에서는 메인 상단과 카드의 이동 정보 영역에 `위치 없이 추천 중`을 표시한다. 출발 준비 화면은 사용자의 추가 동작 없이 위치 권한을 요청하지 않는다.

## 현재 데이터 처리

- 추천, 메인 카드 이동시간 및 출발 계획 API 요청 본문으로 위도와 경도를 전송한다.
- 좌표는 계정과 저널 기록에 저장하지 않는다.
- 메인 이동시간의 React Query 메모리 키에는 좌표가 포함될 수 있지만 영속 저장하지 않는다.
- 장거리 출발 교통거점 경로는 약 100m 단위 위치 구간을 키로 최대 30분 동안 서버 메모리에 보관하고 만료 시 삭제한다.
- 목적지 주변 장소 캐시는 공개된 관광지 좌표만 사용하므로 현재 위치 처리와 분리한다.
- 사진의 촬영 위치는 위치기반서비스 약관에 동의한 경우에만 읽어 주변 장소 자동 선택에 이용한다. 업로드 이미지는 다시 인코딩하여 EXIF 위치 메타데이터를 제거한다.

## Kakao 외부 처리 확인 기록

- 카카오비즈니스 약관은 카카오디벨로퍼스를 비즈서비스에 포함하고, 카카오가 회원으로부터 개인정보 처리업무를 위탁받아 수행한다고 규정한다.
- 같은 약관은 API 사용 과정에서 회원이 이용자 데이터를 카카오에 전달할 때 위수탁 계약 또는 제3자 제공 동의 절차 등 적용 법령을 회원이 확인·준수하도록 규정한다.
- 공개 약관만으로는 Tuti가 사용하는 지도 경로 API의 좌표가 위탁 범위에 포함되는지, 보유기간과 자체 이용 여부가 무엇인지 엔드포인트별로 확인되지 않는다.
- 카카오모빌리티 디벨로퍼스 공개 운영정책에도 길찾기 API 요청 좌표의 법적 처리 관계와 보유기간이 구체적으로 기재되어 있지 않다.
- 따라서 Kakao Developers와 Kakao Mobility Developers에 아래 내용을 서면 문의하고 답변을 보관한다.
  1. Tuti 서버가 이용자 ID 없이 출발지·목적지 좌표와 장소명을 전송하는 구체적인 API 구조
  2. 좌표를 Tuti의 요청에 따른 경로 산출 목적으로만 처리하는지 여부
  3. 처리위탁 또는 제3자 제공 중 적용되는 관계와 근거 약관·계약 조항
  4. 요청·접근 로그를 포함한 보유 항목, 보유기간, 파기 방식과 자체 서비스 개선 이용 여부
  5. 재위탁, 국외 이전 및 추가 계약 또는 개인정보 처리위탁 약정 필요 여부
