# 앱 전환과 일회성 약관 진입 변경 이력

상태: 완료된 전환의 요약. 현재 설치·배포 절차는
[Android](../android-build.md), [iOS](../ios-build.md),
[API 구조](../capacitor-api-architecture.md), [약관 운영](../legal/README.md)을 따른다.

## Capacitor 전환

2026-07-21 계획의 웹·앱 공통 코드, 정적 앱 번들, 원격 API, Bearer 세션,
안전 영역과 히스토리·모션 분리 원칙은 현행 구조 문서로 이관했다.
당시 `/` 추천 홈·`/journal` 라우트·단계별 미완료 체크박스는 현재와 다르므로
로드맵을 삭제했다. 원문은 Git 이력의 `docs/capacitor-app-transition-roadmap.md`에 남는다.

현재 `/`는 하루마디 책장, `/explore`는 작은 여행, `/madi`는 마디 목록이다.
책등·캐러셀 홈은 처음 논의한 후보이지 현재 제공 뷰가 아니다.

## 1.4.0 (12)

- 2026-10-22 확정 약관 묶음을 앱에 포함하고 빌드 시 무결성을 확인했다.
- 앱 먼저 출시 후 서버 전환을 진행했다. 업로드·설치 자체를 약관 시행이나 동의로 취급하지 않았다.
- 최초 계약 적용과 공고는 별도 승인·DB 기록을 통해 2026-10-23 수행했다.
  구체 시각은 [법적 문서 안내](../legal/README.md)를 따른다.

## 1.4.1 (13)

- 삭제된 테스트 계정의 세션이 남는 문제에 대응해 네이티브 세션·대기 약관 상태만
  최초 한 번 정리했다. 전체 Preferences나 서버 자료를 지우는 기능이 아니다.
- 같은 완료 키를 유지해 이후 업데이트마다 로그아웃하지 않는다. 이 처리를 일반적인
  버전 업그레이드 정책으로 반복하지 않는다. 웹에는 적용하지 않는다.
- 일반약관 동의 POST의 401은 세션을 정리하고 다시 명시적으로 확인하도록 한다.
  다른 계정으로 자동 동의 재전송하지 않는다.
- 구서버 약관 응답으로 통과시키는 경로를 제거했다. 서버 원문·계정별 영수증·권리
  행사 경로는 유지한다. 익명 세션 정리는 이전 자료 접근을 잃을 수 있는 별도 위험이다.

이 문서는 새 계정 생성·삭제·공고·동의나 앱 심사 승인을 지시하지 않는다.
최신 출시 내용은 [출시 노트](../release-notes.md), 진입 캐시는
[시작 성능](../startup-performance.md)에서 관리한다.
