# 이전 사업모델 탐색 요약

상태: 과거 검토. 2026-09-07~08의 사업모델 논의·B2C 시나리오·매출 시뮬레이션을
통합했다. 당시 수치와 가상 인물은 실제 인터뷰·결제·매출 결과가 아니다.

## 더 이상 실행 기준으로 쓰지 않는 전제

- B2B 집계 데이터·정기 리포트를 먼저 판매한다는 우선순위.
- 디지털 PDF를 5,900원에 판매하고 실물 상품을 계산에서 제외한 수익 모델.
- 광고 크레딧 90만 원, 임의 클릭 단가·전환율로 만든 90일 매출 예상.
- 추천 중심 서비스의 출시 당시 계정 수·출시 상태를 현재 조건으로 재사용하는 것.

위 전제의 가격표·월 매출 목표·전환 계산은 현행 상품과 맞지 않아 제거했다.
원래 분석은 Git 이력의 `docs/business-model-strategy.md`,
`docs/b2c-scenario-exploration.md`, `docs/b2c-revenue-simulation.md`에 남아 있다.

## 이후에도 유지하는 판단

- 추천·기본 기록·열람을 억지로 불편하게 만들어 결제를 유도하지 않는다.
- 개별 기록·정밀 위치·개인 행동을 판매 상품으로 삼지 않는다.
- 고객마다 별도 앱을 만드는 SI보다 공통 제품을 우선한다.
- 가상 시나리오와 구매 의향은 수요 증거가 아니다. 정상가 결제·제작 원가·반복 구매를 따로 검증한다.
- NFT, 장소 보관·공동 선택, 외출 가이드·오디오, 접근성 가이드, 이용권·예약,
  선물권 등은 당시 비교 후보였으며 구현 약속이 아니다.

## 현재 기준

Tuti는 라이프로그 서비스다. 무료 마디·디지털 하루마디를 기반으로 실물 하루마디
단건 판매를 먼저 검증하고, 기관 프로그램은 후순위로 둔다. 20~25세 여성·커플과
2~3만 원 가격대는 여전히 고객·가격 가설이다. 결제·제작·배송은 제공 중이 아니다.

상세 기준은 [제품 방향](../product-direction.md)과
[하루마디 BM 검증 계획](../harumadi-bm-validation-plan.md)에서만 관리한다.
