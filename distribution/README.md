# 스토어 제출 자료

`google-play/whatsnew/whatsnew-ko-KR`는 Android Release Actions가 내부 테스트 업로드에 사용한다.
이 원문과 `docs/release-notes.md`의 해당 버전 공통 출시 노트는 동일하게 유지한다.

`app-store/ko-KR/`의 소개·부제·프로모션 텍스트와 `google-play/ko-KR/`의 짧은 소개는
스토어 콘솔에 입력할 준비 문안이다. 바이너리 업로드만으로 자동 적용되지 않는다.
App Store의 ‘이 버전에서 업그레이드된 사항’은 공통 출시 노트 원문을 사용한다.
Google Play의 자세한 설명도 App Store description.txt와 같은 기능 범위를 사용한다.
