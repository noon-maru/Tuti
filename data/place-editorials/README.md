# 장소 소개·행동 문구 보완

2026-11-17 개발 DB 점검 및 반영 기록이다. 운영 DB에는 반영하지 않았다.
별도의 LLM API나 외부 수집 API를 호출하지 않고 저장된 공개 장소 원문을 읽어 작성했다.

## 반영 범위

| 항목 | 결과 |
| --- | ---: |
| 추천·공개 조회 가능 장소 합집합 | 13,702곳 |
| 소개 요약 또는 행동 추천 누락 (반영 전) | 8,975곳 |
| 원문을 근거로 새로 작성·반영한 장소 | 140곳 (요약 140개·행동 140개) |
| 기존 요약 원문 대조 완료 | 138곳 |
| 원문과 일치하여 기존 요약 노출을 복원 | 104곳 |
| 사실 불일치 등으로 복원하지 않은 기존 요약 | 34곳 |
| 아직 원문 대조하지 않은 기존 요약 | 276곳 |
| 소개 원문이 없어 작성하지 않은 누락 장소 | 8,835곳 |

기존 요약 414곳은 텍스트 누락이 아니라 원문 지문 불일치로 숨겨져 있었다.
104곳은 원문과 문구를 대조한 뒤 지문만 갱신했으며 기존 요약 텍스트는 바꾸지 않았다.
나머지 310곳은 숨김 상태를 유지한다. 원문이 없는 장소는 제목·주소만으로 체험이나 시설을 만들어 넣지 않았다.

## 파일과 근거

- `2026-11-17-{a,b,c}.jsonl`: 새 문구 140건. 서브에이전트가 원문을 직접 읽고 작성했다.
- `2026-11-17-review-b.jsonl`: 기존 요약 138건의 승인 여부·근거. 중단된 검토의 나머지는 주 에이전트가 직접 대조했다.
- `source/2026-11-17/`: 작성·검토 당시 공개 원문 스냅샷. `stale-a`, `stale-c`는 미검토 자료다.
- `source/*/unsupported.jsonl`: 재생성 가능한 원문 미확보 목록으로 Git 추적에서 제외한다.

원문 품질 주의 대상: 4025583(카페 이름이지만 브랜드 소개만 있음), 2648607(단일 시설이 아닌 용인8경 모음),
4012676·4027247(브랜드 중심 소개). 해당 자료로 확인되지 않는 메뉴·시설·반려견 동반 조건은 추가하지 않았다.

## 도구

`scripts/export-place-editorial-backfill.ts`는 기본적으로 집계만 한다. `--export`는 스냅샷을 작성하므로
기존 근거 디렉터리에 다시 실행해 덮어쓰지 않는다. 연결할 DB는 실행 환경에서 지정한다.

`scripts/import-place-editorial-backfill.ts`는 `--input 파일`을 반복 지정한다.
기본은 읽기 전용 계획이며, `--apply --expected-plan-hash 계획해시`가 있어야 반영한다.
기존 요약 지문 복원은 별도로 `--review`를 지정한다.
원문 지문·문구·수정 시각·추천 범위를 확인하고 트랜잭션과 행 잠금으로 동시 편집을 보호한다.
새 문구 반영은 빈 필드만 채우며 기존 편집값과 체험 원문을 덮어쓰지 않는다.

상세 화면은 체험 원문이 있으면 우선 표시하고, 없으면 저장된 행동 추천을 보여준다.
일반적인 추천 진행 단계 문구를 실제 장소의 활동 안내로 대신 표시하지 않는다.

## 소개 원문 누락 원인 추가 조사 (2026-11-17)

개발 DB의 누락 8,835곳 **전부 상세정보 레코드가 없었다**. 소개가 없는 상세 응답을 성공적으로 저장한 경우가 아니다.
장소 목록 원본·반려동물 원본의 다른 소개 필드도 함께 점검했으나 대체 소개를 발견하지 못했다.
이는 제공자가 소개를 제공하지 않는다는 뜻이 아니라, 저장된 자료가 기본 목록과 동반 정보에 머물러 있다는 뜻이다.

| 유형 | 상세 레코드 없는 장소 |
| --- | ---: |
| 관광지 (12) | 63 |
| 문화시설 (14) | 3 |
| 레포츠 (28) | 10 |
| 숙박 (32) | 62 |
| 쇼핑 (38) | 8,634 |
| 음식점 (39) | 63 |

유형별·ID 구간별로 31곳을 표본 선정하여 국문 TourAPI `detailCommon2`를 읽기 전용 조회했다.
관광지 4곳·쇼핑 12곳·레포츠 4곳·숙박 3곳, **정상 응답 23곳 모두 실제 소개 원문이 있었다**.
다음 숙박 표본(3532732)은 HTTP 429로 확인되어 추가 조회를 중단했다.
따라서 31곳 중 23곳 확인 완료, 1곳 요청 제한, 7곳 미조회이며 전체 8,835곳의 원문 존재율로 일반화하지 않는다.

확인 예: 부용대(1180825), 소래습지생태공원(1618031), 신세계사이먼 파주 프리미엄 아울렛(1238580),
나이키 문정점(2914845), 제주레일바이크(2705373), 보노펜션(138900).

코드상 원인:

- `registerDogPlace.ts`: 기본 정보·동반 정보로 카탈로그를 등록하며 상세 소개 수집은 별도 단계다.
- `enrich-tourism-place-editorials.ts`: 예전 저부담 평가의 `enrich` 후보만 소개 수집 대상으로 선택한다.
- `supplement-dog-place-details.ts`: 지정한 ID를 최대 20곳씩 보완하는 도구로, 전체 신규 카탈로그 자동 수집 경로가 아니다.

즉 **추천·검색 가능 범위는 넓어졌지만 소개 수집 범위가 따라가지 못한 구조**가 확인된다.
과거 모든 실행 이력을 증명하는 것은 아니지만, 현재 DB 상태와 도구 구조는 원문 부재보다 상세 수집 누락을 뒷받침한다.

다음 단계는 전체 카탈로그 기준의 재개 가능한 상세 수집 큐를 구성하고, 일일 호출 한도 안에서
빈 필드만 보완한 다음 직접 문구 작성 대상을 다시 추출하는 것이다. 이 조사에서는 DB를 수정하거나 수집 작업을 일괄 실행하지 않았다.

재점검 도구: `scripts/audit-missing-place-overviews.ts`. 기본은 DB 조회만 수행하며,
`--sample-api`를 붙이면 외부 API 표본을 순차 조회한다. `--sample-offset=N`으로 표본 시작 위치를 지정한다.
인증·호출 한도 오류에서는 즉시 중단하며 API 키·URL·사용자 데이터를 출력하지 않는다.
